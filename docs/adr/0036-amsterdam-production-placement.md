# Единственная рабочая площадка в Амстердаме

20 октября 2026 года в #1575 владелец выбрал перенос Platform, Logto, PostgreSQL,
RabbitMQ и Telegram на Timeweb Cloud AMS вместо постоянного входа через Aeza в российское
приложение. Цель состоит в устранении зависимости рабочего приложения и исходящего Telegram API
от российского сетевого маршрута. Географическое разделение базы и два одновременно пишущих
экземпляра не вводятся. Существующие домены сохраняются; старые IP временно пересылают запросы
на единственную актуальную площадку.

После первых записей в AMS российская база является устаревшим снимком. Возврат требует сохранения
актуальных данных, а не одного изменения DNS. Это техническое решение владельца, а не заключение
о соблюдении требований к персональным данным: [исследование](../research/issue-1575-ams-personal-data-placement.md)
оставляет соответствие открытым. Действующие политики и уведомления этим ADR не изменяются.
[Состояние, проверки и восстановление](../runbooks/production-amsterdam.md) принадлежат runbook.
