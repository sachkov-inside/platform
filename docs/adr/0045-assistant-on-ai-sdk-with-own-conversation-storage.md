# Помощник на Vercel AI SDK со своим хранением разговора

Владелец принял решение 07.11.2026 в тикете «Помощник: техническое устройство» (#1983).
Сравнение библиотек: исследование «Помощник: библиотека агента на TypeScript» (#1977).

## Контекст

Помощнику нужен агентный цикл с инструментами, потоковый ответ и своя модель памяти.
Модель памяти такая: один сплошной чат на Account, эпизоды и короткий пересказ прошлых эпизодов.
Сценарии выполняет код, модель их только запускает. Данные учеников не уходят третьим сторонам
без явной настройки: передача провайдеру модели остаётся условием production-запуска по 152-ФЗ.

## Решение

Помощник работает в модуле `assistant` процесса `api` на Vercel AI SDK 7 (`ToolLoopAgent`).
Библиотека даёт цикл, вызов провайдера и формат потока `UIMessage`. Всё состояние лежит в схеме
`assistant` через Prisma: разговор, сообщения, эпизоды, пересказ, запуски Сценариев, журнал
событий хода и журнал шагов модели. Провайдер подключается через OpenAI-совместимый endpoint
и выбирается настройкой. Пакет `ai` имеет одну версию для `apps/backend` и `apps/telegram`
через каталог pnpm.

Ход принадлежит серверу, а не HTTP-запросу. Сервер доводит ход до конца, даже если клиент ушёл.
На разговор приходится один активный ход. Ход пишет события в таблицу с порядковым номером.
Подписчики, то есть вкладки и устройства одного Account, получают события из памяти процесса.
После перезагрузки или обрыва сети клиент называет последний номер, и сервер досылает пропущенное.
Кнопка «Остановить» прерывает вызов модели отдельным запросом и сохраняет часть ответа.
Ход, оборванный перезапуском сервера, получает отметку «прерван».

Механизм `resumable-stream` из AI SDK не используется: он требует Redis, а Redis в Platform нет.
Рассылка из памяти опирается на один процесс `api` в production. Если `api` запустят
в нескольких копиях, рассылку заменит RabbitMQ или PostgreSQL. Таблица событий и клиент
при этом не меняются.

Журнал шагов хранит модель, токены, стоимость, входы и выходы инструментов и время каждого шага.
Он заменяет Langfuse из решения #786 от 27.09.2026. Langfuse требует шесть сервисов, среди них
ClickHouse, поэтому он не развёрнут. Экспорт OpenTelemetry можно добавить позже без смены журнала.

## Рассмотренные варианты

- **Mastra** даёт готовую память и workflow. Но `@mastra/core` содержит закрытый код `ee/`,
  по умолчанию шлёт телеметрию в PostHog и хранит состояние в своих таблицах `mastra_*`.
- **OpenAI Agents SDK** по умолчанию отправляет трассы в OpenAI.
  С 19.08 по 20.10.2026 у него вышли пять ломающих версий.
- **LangGraph.js** хранит историю внутри своих снимков состояния и приносит слой LangChain.
- **Claude Agent SDK** имеет закрытую лицензию и работает только с Claude.

## Последствия

- Память, пересказ, эпизоды и evals пишет Platform. Зато их правила видны в коде и проверяются
  без внутренних порогов библиотеки.
- Мажорная версия AI SDK ломает API примерно раз в полгода. Переход идёт через codemod
  и проверку обоих приложений.
- Если долгая память или длинные Сценарии с ожиданием человека станут большими, сравнение
  с Mastra повторяют. Начинают его с проверки состава `ee/` и телеметрии.
