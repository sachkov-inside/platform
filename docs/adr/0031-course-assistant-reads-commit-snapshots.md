# GitHub App только на чтение и снимок репозитория по commit SHA

Решения владельца от 27.09.2026 ([ai-engineering#122](https://github.com/sachkov-inside/ai-engineering/issues/122),
Specification [#786](https://github.com/sachkov-inside/platform/issues/786)) требуют трёх вещей.
Серверный агент читает работу участника из GitHub по его доступу. Проект участника не запускается.
Код участника не хранится. Подключение репозитория через GitHub App курса только на чтение появилось
в [#787](https://github.com/sachkov-inside/platform/issues/787). Проверка практики в
[#788](https://github.com/sachkov-inside/platform/issues/788) впервые читает сам код.

## Решение

- GitHub App курса просит только `metadata`, `contents` и `pull_requests` на чтение. Установка с
  более широкими правами отклоняется. Каждый токен для чтения репозитория сужается до одного
  репозитория Repository Link и этих прав. Отказ GitHub выдать такой токен значит, что доступ
  отозван.
- Проверка читает один точный коммит: голову основной ветки или открытого PR этого же репозитория.
  PR из форков не рассматриваются: это предложение агента, решение за владельцем. Если вариантов
  несколько, участник выбирает сам. SHA проверенного коммита сохраняется в Practice Review.
- Архив этого коммита скачивается во временный каталог worker и распаковывается только в обычные
  файлы: ссылки, устройства и выход за каталог отбрасываются. Размер архива и распакованного снимка
  ограничен. Снимок удаляется сразу после проверки, успешной или нет.
- Модель читает снимок только инструментами обзора, списка файлов, поиска текста, чтения диапазона
  строк и сравнения PR с базой. Ответы инструментов ограничены по размеру. Запуска кода и записи нет.
- В базе остаются пути и номера строк свидетельств, объяснения модели и SHA, но не содержимое
  файлов.

## Последствия

- Незакоммиченная и неотправленная работа проверке недоступна, и помощник говорит об этом прямо.
- Каждая проверка скачивает архив заново: кэша кода нет, повторная проверка всегда видит текущий
  коммит.
- Webhook GitHub не нужен: отзыв доступа виден при следующем чтении.
- Проверка поведения, которое видно только при запуске, остаётся за участником: помощник отмечает
  такой критерий `not_verified`, а не `violation`.
