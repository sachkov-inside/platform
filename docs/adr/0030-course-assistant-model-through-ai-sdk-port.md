# Модель помощника курса через Vercel AI SDK и порт модуля

Владелец 27.09.2026 решил, что помощник курса — собственный модуль backend на Vercel AI SDK:
готовые агенты и облачные сервисы агентов не используются, модель и поставщик выбираются позже по
evals ([ai-engineering#122](https://github.com/sachkov-inside/ai-engineering/issues/122), журнал
решений курса; Specification [#786](https://github.com/sachkov-inside/platform/issues/786)).
Первая проверка практики появилась в [#788](https://github.com/sachkov-inside/platform/issues/788),
и вместе с ней понадобилось закрепить, где проходит граница модели.

## Решение

Модуль `course-assistant` получает модель через свой порт `ReviewModel`. Порт — это `LanguageModel`
Vercel AI SDK, название поставщика, идентификатор модели, таблица цен и лимиты проверки. Production
собирает его из OpenAI-совместимого поставщика (`@ai-sdk/openai-compatible`): адрес, ключ, модель и
цены — настройки `COURSE_ASSISTANT_MODEL_*`, их смена не меняет код. Тесты подставляют
детерминированную `MockLanguageModelV4` из `ai/test` с тем же портом.

Цикл агента — `generateText` с инструментами только на чтение и лимитом шагов и токенов. Итог
проверки принимается только из вызова инструмента `submit_review`, чья схема построена по критериям
задания. Статус практики вычисляет сервер из этого итога; текст модели вне вызова статус не меняет.
Каждый шаг цикла записывается как Assistant Usage с токенами ответа поставщика и стоимостью по
версии таблицы цен.

Чат практики в web — `useChat` AI SDK UI под компонентами assistant-ui. Поток AI SDK UI отдаёт BFF
фичи `practice-review`. Он ставит команду через обычный REST backend и перечитывает проверку, пока её
выполняет worker. Backend остаётся JSON REST с OpenAPI; поток не проходит через сгенерированный
клиент.

## Последствия

- Смена модели или поставщика — настройка стенда; выбор делает владелец по evals (#791).
- Поставщик должен поддерживать вызов инструментов. Модель без них не пройдёт проверку: итог вне
  `submit_review` считается сбоем `invalid_report`.
- Повтор сбоя поставщика не выполняется внутри цикла (`maxRetries: 0`), чтобы весь расход оставался
  видимым в Assistant Usage. Отложенную проверку после повторов вводит #789.
- Модели другого семейства (не OpenAI-совместимые) подключаются новым адаптером того же порта.
