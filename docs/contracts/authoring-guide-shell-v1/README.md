# Выпуск оболочки Guide: контракт пакета v1

Platform #803 владеет этим контрактом; exporter Inside Content реализует его в
[inside-content#12](https://github.com/sachkov-inside/inside-content/issues/12). Исходная
постановка — [выпуск оболочки курса](https://github.com/sachkov-inside/ai-engineering/blob/main/docs/course-shell-release-plan.md).
Исполняемая authority — `tools/authoring/package.mjs`, `local-sync.mjs`, `release.mjs` и
`tools/authoring/guide-shell.test.mjs`, который загружает [пример пакета](package.json).

## Зачем

Страница продукта, карточка, краткое описание и вся программа глав переносятся раньше уроков.
Обычный пакет требует хотя бы один выбранный Material. Пустой список материалов в нём был бы
неоднозначен: «ничего не менять» или «убрать всё». Поэтому выпуск без материалов объявляется явно.

## Форма пакета

Пакет остаётся `schemaVersion: 1` в каноническом JSON. Оболочку задаёт поле
`selection.scope: "guide-shell"`. Без поля пакет обычный, и прежние ограничения сохраняются:
пустые `selection.materialIds` отклоняются с подсказкой объявить оболочку.

В режиме оболочки обязательно:

- `selection.guideId` называет ровно один Guide, и `guides` содержит только его;
- `selection.chapterIds`, `selection.materialIds`, `materials`, `assets` пусты;
  `practiceDefinitions` отсутствует или пуст;
- у Guide `complete: true`, полный список `chapters` в нужном порядке;
- `guide.materialIds`, `guide.supplementaryMaterialIds` и `materialIds` каждой главы пусты.

Остальные поля Guide (`slug`, `presentation`, `page`, `title`, `summary`) имеют прежний смысл
[ADR 0026](../../adr/0026-guide-page-from-source-data.md). Идентичность главы по-прежнему выводится
из `sourceNamespace`, Guide и `sourceId` главы, поэтому главы нельзя переименовывать через
`sourceId` без потери привязки уже размещённых уроков.

## Что делает перенос

- Резервирует или находит Guide по source key и обновляет страницу, карточку, описание,
  адрес и оформление, только если они отличаются.
- Передаёт список глав пакета поверх материалов, которые уже есть в Guide на цели. Их порядок и
  главы сохраняются. Неизменная оболочка ничего не пишет, повтор не создаёт дублей.
- Не создаёт, не меняет, не публикует и не архивирует Material, artifacts, практику, обложки,
  видео и предложения покупки. Guide закрепляется на Home только по отдельной опции локального
  просмотра, как и в обычном переносе. Архивных предложений нет:
  отсутствие материалов в оболочке не означает их удаление. `--archive` отклоняется.
- Если пакет убирает главу, в которой на цели уже есть материалы, перенос останавливается до
  первой записи. Такие материалы сначала перемещаются в Platform, либо глава остаётся в пакете.
- Незавершённые записи материалов из прерванного обычного переноса оболочка не продолжает и
  сообщает о них: preview полем `pendingMaterialWrites`, отчёт apply notice `journal_pending`.
  Их завершает повтор переноса того же пакета.

## Предпросмотр и точное применение

`authoring:release preview` показывает `scope: "guide-shell"`, пустые `materials` и
`archiveProposals`, а для Guide — изменение страницы, текста глав и
`chapterListChange: { added, removed }`. `added`/`removed` материалов в режиме оболочки равны нулю.
`apply` принимает только этот preview: отпечаток включает `scope`, версию Guide и версию порядка, поэтому
любое изменение цели после просмотра останавливает запись. Production target этим контрактом не
открывается; доверенная доставка — [platform#805](https://github.com/sachkov-inside/platform/issues/805).

## Что делает exporter

Exporter Content добавляет явный выбор оболочки (флаг CLI и `tools/platform_package.py`), а не
выводит его из пустой выборки. Он пишет весь список глав выбранного Guide, страницу и тексты
Guide из выбранного SHA и ни одного тела урока, вложения или контекста практики. Обычный экспорт
не меняется. Stage исходных материалов оболочка не читает и не меняет.
