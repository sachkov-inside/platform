Это история сверки, не новый визуальный стандарт. Итоговые проверки приложения, артефакты и решение о доставке находятся в связанном с #2261 PR.

## Охват

Найдены все пять `Temporary semantic UI`: четыре в `apps/web/src` и один в локальном инструменте `scripts/local-accounts-view.mjs`. Им соответствуют четыре открытые integration issues (#1554, #1744, #1547, #1642) и уже закрытая #1278, перенесённая в #1427. Первоначальный поиск только по Web пропустил локальный инструмент; независимое ревью восстановило полный охват.

[Предыдущий аудит](2026-11-16-architecture-audit.md#где-агент-легко-ошибается) зафиксировал четыре маркера внутри Web. [PR #2237](https://github.com/sachkov-inside/platform/pull/2237) отдельно перечисляет пятый локальный маркер и разрешённый путь закрытия #1642 без отдельной визуальной приёмки. Закрытая #1278 сама по себе не доказывает реализацию или принятие.

## История приёмки

[Текущий frontend delivery](../agents/frontend-delivery.md#delivery-contract) принимает вид один раз в PR после проверки приложения и классификации. Записи прежнего отдельного production visual GO в `DESIGN.md` теперь явно исторические. Это не новое согласие за владельца и не приёмка позднейших ревизий.

Для Task Submissions найдено более позднее свидетельство: [PR #1353](https://github.com/sachkov-inside/platform/pull/1353) записывает production visual GO для своей ревизии, объединённой в `91c6b4924c1accf10946dd9875a20412a1f106e8`. Прежняя фраза «ещё не получен» без указания ревизии скрывала эту запись. Остальные исторические записи говорят только о том, чего этот файл не записал, а не об отсутствии любого решения в истории.

Candidate authoring workbench из #38 не стал глобально принятым: перенос его композиции на новые поверхности по-прежнему требует выбора направления по текущему контракту. Отклонённая version rail не возвращается.

Обобщение о перечитывании всех поверхностей при каждом возврате во вкладку удалено из визуального стандарта. Политикой свежести владеют [ADR 0027](../adr/0027-web-navigation-and-caching.md) и [Web standard](../../apps/web/CODING_STANDARDS.md#server-state-and-mutations): обычное окно свежести и явно self-refreshing чтения различаются.

## Пределы сверки

Поиск и чтение импортов доказывают текущую композицию, но не заменяют проверку поведения в браузере. Component stories проверяют труднодоступные состояния настоящих модулей; итоговый PR отдельно показывает доступные сценарии приложения. Новый визуальный мир, измерение всего bundle или полная сертификация WCAG не входят в эту сверку. Цвета, размеры и компоненты не переопределялись ради удаления исторических пометок.
