# Место урока на карточке каталога «Материалы»

Задание владельца 2026-11-12. Прототип: `apps/web/src/_pages/library-discovery/ui/library-card-place-prototype.stories.tsx`,
story `Prototypes/Library Card Place`.

Вопрос: подпись «Глава N · урок M» стояла внизу растянутой карточки (`mt-auto`). Под тёмной карточкой
без обложки она уплывала к следующему ряду и читалась как его подпись.

Варианты: 0 как было; A бейдж на картинке; B чип под карточкой; C место в подписи формата тёмной
карточки и строкой над названием у карточки с обложкой; D место строкой сразу под картинкой у всех.

Решение владельца (2026-11-12): D. Место всегда в одном месте, прямо под иллюстрацией до названия,
даже если название стоит на самой картинке.

Снимки 1440 px: `0-desktop.png` … `D-desktop.png`.
