Первые два урока главы 1, подготовительная глава и дополнительный бриф бесплатны.
Остальные три урока видны в программе, но требуют покупки. Тестовая цена — 30 рублей;
вместо реального списания открывается двойник банка. Подтверждение почты для чека также
приходит в Mailpit. Для проверки MCP войти тем же аккаунтом, что и на сайте.

В этой рабочей директории после остановки стенда:

```bash
fnm exec --using 24.21.0 pnpm local:stand --production-web
```

Для переноса новой **закоммиченной** версии материалов из Obsidian/Inside Content:

```bash
fnm exec --using 24.21.0 pnpm local:course
```

Команда обновляет данные работающего стенда. После неё обновить страницу браузера.
Несохранённые и незакоммиченные правки не переносятся. Для другого checkout/commit
доступны `--content PATH --ref COMMIT`. Оригиналы и их editorial stages не меняются.

Остановка с сохранением материалов, пользователей, оплаты и прогресса:

```bash
docker compose --profile identity down
```

Не добавлять `-v`. Полный контракт запуска и синхронизации:
[local-development.md](../../runbooks/local-development.md#ai-engineering-course-acceptance-stand).

## Границы результата

Продающее описание и обложки отложены владельцем. Используется существующее краткое
описание и стандартные карточки. Цена и бесплатные уроки — локальный проверочный профиль.

([#780](https://github.com/sachkov-inside/platform/issues/780)); сохранённый grant тестового
оффера бессрочный, поддержка — 6 месяцев. Это не публичные условия курса.

В локальной инструкции проверен Codex. Claude Code, реальная оплата, production OAuth,
публикация и запуск продаж не проверялись и не применялись. Программа отражает имеющиеся
материалы; будущие главы не выдумывались.
