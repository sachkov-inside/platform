# Минималистичные действия материала — #1558

Исторический отчёт. В PR [#1608](https://github.com/sachkov-inside/platform/pull/1608) показ «Поделиться» в карточках и у закрытых материалов отменён. Текущий контракт: только внутри публичного материала, в панелях действий Reader. Ниже сохранены исходные результаты и снимки прежнего поведения.

Коррекция владельца: по примеру строки действий X кнопка представлена одним приглушённым значком, без видимой подписи, рамки и отдельной панели. Это единый production MaterialShareButton в feed/row/series и Reader. При успешном копировании появляется галочка и объявление для экранного диктора; лишнего текста и сдвига соседних действий нет. Ручной URL открывается только при отказе clipboard. Счётчик #1556 не подменяется фиктивными числами и не включён.

Снимки настоящих production-owned компонентов Storybook просмотрены. На 390/1440 нет горизонтального переполнения; axe WCAG2A/AA/2.1AA:0. Доступное имя сохранено, область нажатия не меньше44px: на телефоне стандартная компактная кнопка имеет видимые36px и расширенную область через псевдоэлемент44px.

В браузере WebKit прошли Default, CopyLink, NativeMenu, CancelMenu, ManualCopy, NativeUnavailable, CompactManualCopy и существующий DesktopRouteDetails. Default и CopyLink теперь явно проверяют отсутствие текстового содержимого кнопки и доступный title. Действие Share подменено, сообщений никто не отправлял. Final-head provider CI остаётся отдельным требованием; локальный MCP runner имеет известную ошибку #1551.

Требование закреплено в platform-mvp-brief и SEO specification. Окончательное визуальное согласование остаётся в #1554.
