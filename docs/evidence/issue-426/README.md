# Прохождение серии — #426

Дата: 2026-09-08. Изменённый production-компонент используется и страницей серии, и Storybook.
Снимки получены локально; это не свидетельство деплоя или приёмки владельцем.

## Визуальные состояния

Storybook: `Pages / Mobile-first Platform / Series Journey`.

- `storybook-desktop.png`, `storybook-mobile.png`: отдельный блок прогресса, продолжение, вертикальный маршрут.
- `storybook-guest-mobile.png`: первые три бесплатных материала и остальные по подписке.
- `storybook-pagination-320.png`: вторая страница длинной серии на экране 320 px.
- `storybook-error-320.png`: ошибка прогресса и повторная загрузка.
- `storybook-text-zoom-200.png`: увеличение текста до 200% на 320 px.
- `responsive-accessibility.json`: отсутствие горизонтального переполнения, результаты Axe для пяти основных состояний; отдельно проверены 200% текста для ошибки, прогресса и гостя.

Фикстуры Storybook иллюстрируют серию из 24 материалов. Они не подтверждают серверные правила.
Дополнительные stories покрывают бесплатный аккаунт, закончившуюся подписку, завершение,
загрузку, сбой проверки доступа и короткую серию. Проверки геометрии на mobile/desktop
подтверждают сохранение положения маршрута после загрузки прогресса.

## Реальная локальная интеграция

`live-desktop-chromium.png`, `live-mobile-chromium.png` получены через production Next.js,
BFF, API и локальную PostgreSQL на синтетических demo-данных. Проверены последние реальные
открытия двух материалов, продолжение последнего, переход к нему в маршруте, перезагрузка,
возврат из Reader, отсутствие лишней пагинации в короткой серии, гостевой доступ и Axe.

`live-page-two-desktop-chromium.png`, `live-page-two-mobile-chromium.png` получены для серии
из 13 опубликованных материалов, созданной и упорядоченной через authoring API. Проверены
страница 2, переходы Back/Forward, возврат из Reader, URL с `page` и `at`, перезагрузка,
сквозной номер и общий знаменатель прогресса. После проверки серия архивируется через API.

Команды и итоговый коммит зафиксированы в отчёте PR. Использованы Node.js 24.19.0 и pnpm 11.22.0.

## Закрытие замечаний

- Сдвиг маршрута при загрузке прогресса: зарезервирована высота блока и ограничен заголовок
  продолжения двумя строками; добавлены проверки геометрии.
- Переполнение при 200% текста: строка материала адаптируется через container query,
  длинные кнопки переносятся; добавлены три проверки увеличенного текста.
- Недостаточное доказательство пагинации через живой маршрут: добавлен отдельный fullstack-сценарий на 13 материалах.
- Два advisory дизайн-детектора относятся к существующим размерам шрифта других вариантов
  MaterialCard; эти строки не менялись, новых нарушений детектор не обнаружил.

Реальные внешние Logto, платежи и Kinescope этим набором не проверяются. Механизм подписки,
админская настройка доступа и видеоплеер не меняются. Визуальная приёмка и merge остаются
отдельными решениями владельца.
