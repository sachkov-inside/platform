# Platform #601: отказ по расхождению редакции

Отказ `revision_conflict` на шаге «Получить код» теперь говорит «Данные изменились. Повторите
действие.» — формулировка владельца от 15.09.2026. Прежний текст отправлял искать другую вкладку,
хотя после #578 вкладки одного браузера сходятся сами.

Снимки получены из штатного Playwright-сценария
`apps/web/test/e2e/account-cabinet.spec.ts` («отказ по расхождению редакции показывает текст из
источника отказов») в проектах `desktop-chromium` (1440×1024) и `mobile-chromium` (390×844). Для
съёмки в конец сценария временно добавлялся `page.screenshot` (на mobile — после прокрутки отказа в
центр экрана, чтобы его не закрывал нижний док); этот шаг не закоммичен:

- `refusal-desktop-1440.png`;
- `refusal-mobile-390.png`.

Сценарий подменяет ответ BFF `/api/account/billing/contact/start` закрытым отказом и сверяет
показанный текст с `contactErrorMessage("revision_conflict")`, а не с копией строки. Это
доказательство интерфейса на заглушке BFF, не проверка backend: правило отказа не менялось.

Команда ниже воспроизводит проверку текста; снимков она не создаёт:

```bash
PLAYWRIGHT_PORT=3360 pnpm exec playwright test account-cabinet.spec.ts -g "отказ по расхождению редакции"
```
