# #555 — первый экран личной главной не дёргается при загрузке

Снимки сняты в Storybook, история `Pages/Home/Guest`, в настоящей оболочке страницы
(`publicPageEnvironment("/")`). Storybook воспроизводит дефект теми же числами, что и живой стенд,
поэтому одно окружение показывает и причину, и починку.

| Файл | Что показывает |
| --- | --- |
| `loading-before-desktop-1440.png`, `loading-before-mobile-390.png` | Состояние загрузки до починки: заголовок «Руководства» из рукописного скелета |
| `loading-desktop-1440.png`, `loading-mobile-390.png` | Состояние загрузки после починки |
| `ready-desktop-1440.png`, `ready-mobile-390.png` | Готовая главная без закреплённого руководства — то, чем состояние загрузки сменяется |

Положение и размер заголовка «Руководства», отсчёт от верхнего края окна:

| Состояние | 1440 | 390 |
| --- | --- | --- |
| Загрузка до починки | верх 121, высота 32, интерлиньяж 32px | верх 32, высота 28, интерлиньяж 28px |
| Загрузка после починки | верх 113, высота 30, интерлиньяж 30px | верх 24, высота 23.98, интерлиньяж 23.9994px |
| Готовая главная | верх 113, высота 30, интерлиньяж 30px | верх 24, высота 23.98, интерлиньяж 23.9994px |

Те же 121 и 32 давал живой стенд до починки: сквозной сценарий
`personal Home preserves SSR geometry through authenticated hydration` падал на `121 → 113` и
`32 → 24`. После починки он зелёный на обоих проектах.
