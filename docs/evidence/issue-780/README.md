# Platform #780: оферта редакции 5 и сроки предложения до оплаты

Production-owned поверхности в Storybook сняты при 1440×1024 и 390×844:

- **оплата предложения курса** (`pages-guide-payment--ready`): «Материалы и общий чат — без
  ограничения срока», сопровождение на срок предложения, доли цены «Из них поровну», сводка
  условий с расчётным сроком 12 месяцев и полным возвратом в первые 7 дней;
- **оплата предложения с другими сроками** (`pages-guide-payment--fixed-term-offer`): то же
  предложение с материалами и чатом на 24 месяца и сопровождением на 12 — страница называет
  «2 года гарантированно» и «1 год»;
- **оферта** (`pages-legal-документ--purchase-offer`): действующая редакция 5.

В `results.json` для каждого кадра: отсутствие горизонтального переполнения, отсутствие
serious/critical нарушений axe WCAG2/2.1 A/AA, а для оплаты предложения курса — пустой список
сроков редакции 4 («2 года гарантированно», «Навсегда», «Всё включено») в тексте страницы.
Agentation скрыт только для снимка и axe.

На полностраничных кадрах телефона плавающая нижняя навигация оболочки закрывает часть текста:
она фиксирована к окну, а снимок склеивает всю высоту. Текст под ней виден на кадре компьютера.

Воспроизведение из корня checkout на pinned Node/pnpm:

```bash
pnpm --filter @inside/web exec storybook dev --ci --no-open -p 3401
# Во втором терминале; каталог вывода выбирается отдельно от сохранённых доказательств.
STORYBOOK_URL=http://127.0.0.1:3401 node docs/evidence/issue-780/capture.mjs /tmp/platform780-evidence
```

Это визуальное доказательство настоящих компонентов с fixture-данными, не реальные продажи,
платёжное подтверждение или production. В fixture сопровождение — 3 месяца, цена — 4 900 ₽. Сроки
читаются из снимка предложения; расчётный срок, окно возврата и доли цены —
из `@inside/legal/purchase-terms`.
