# Platform #650: оферта разовой покупки редакции 3 до оплаты

Изменённая реализация: `fd481f8c537cd31c1181f28534c61f348f9d34d2`, база
`a6df3438d22083748da781a259b1a661b4d09e3d`.

Три production-owned поверхности в Storybook проверены при 1440×1024 и 390×844:

- **оплата** (`pages-guide-payment--ready`): состав, сроки «Материалы и общий чат — 2 года
  гарантированно», «Сопровождение автора — 6 месяцев», цена с долями «Из них поровну», блок
  «Условия покупки» над согласием, «Принимаю оферту разовой покупки», ссылки на оферту, условия
  использования, реквизиты и политику данных;
- **страница продукта AI-first** (`pages-guide-ai-first--desktop`): целиком и отдельно раздел
  сопровождения (`product-support-*.png`);
- **оферта** (`pages-legal-документ--purchase-offer`): целиком и отдельно раздел «2. Что входит
  в покупку» со списками (`offer-support-*.png`).

В `results.json` для каждого кадра: отсутствие горизонтального переполнения, отсутствие
serious/critical нарушений axe WCAG2/2.1 A/AA и пустой список старых обещаний («без ограничения
срока», «всё время твоего участия», «Навсегда», «Всё включено») в тексте страницы. Agentation скрыт
только для снимка и axe.

На полностраничных кадрах телефона плавающая нижняя навигация оболочки закрывает часть текста в
середине и внизу: она фиксирована к окну, а снимок склеивает всю высоту. Текст под ней виден на
кадре компьютера.

Воспроизведение из корня checkout на pinned Node/pnpm:

```bash
pnpm --filter @inside/web exec storybook dev --ci --no-open -p 3401
# Во втором терминале; каталог вывода выбирается отдельно от сохранённых доказательств.
STORYBOOK_URL=http://127.0.0.1:3401 node docs/evidence/issue-650/capture.mjs /tmp/platform650-new-evidence
```

Это визуальное доказательство настоящих компонентов с fixture-данными, не реальные продажи,
платёжное подтверждение или production. Цена в fixture — 2 500 ₽; распределение цены и сроки
берутся из `@inside/legal/purchase-terms`. Реакцию оплаты на смену редакции проверяют story
`Pages/Guide/Payment/Flow › EditionChangedBeforePayment`, модульный тест BFF и integration-тест
`apps/backend/test/integration/billing-offer-edition-change.test.ts`.
