## Что проверено вживую, а что нет

Проверено на живом API: введение приходит в `reference.introduction` только для руководства,
а раздел артефактов отдаёт `availability` по общему `ContentAccess` — анонимный посетитель видит
свободный артефакт с адресом, а закрытый без адреса (`externalUrl: null`).

Не проверено вживую: вошедший участник, истёкший доступ и `materials:manage` bypass — эти состояния
сняты в Storybook, а на реальном PostgreSQL их закрывают интеграционные тесты. Полный импорт двух
руководств Inside Content поставляет соседняя задача
[#468](https://github.com/sachkov-inside/platform/issues/468); здесь авторский текст перенесён
вручную ради снимков.

Снимки не являются доказательством деплоя, приёмки владельцем или визуального GO.
