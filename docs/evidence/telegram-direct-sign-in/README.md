# Прямой вход через Telegram

Изменение сохраняет production-owned кнопку и экран ожидания из Storybook. Общий выбор Logto
пропускается параметром официального SDK. Страница ожидания один раз за загрузку пытается открыть
приложение Telegram; запасная HTTPS-кнопка и завершение входа в исходной вкладке сохраняются.

Снимки сделаны в Storybook текущей рабочей ветки при ширине 1440, 390 и 320 px:

| Поверхность | Компьютер | Телефон | Узкий экран |
| --- | --- | --- | --- |
| Шапка сайта | [1440](header-1440.png) | [390](header-390.png) | [320](header-320.png) |
| Ожидание подтверждения | [1440](waiting-1440.png) | [390](waiting-390.png) | [320](waiting-320.png) |

Для всех шести снимков проверено отсутствие горизонтальной прокрутки. Storybook использует
production presentation и синтетические состояния; он не открывает Telegram и не подтверждает
реальный вход. Проверка `test/browser-engines/telegram-sign-in.test.ts` исполняет настоящий скрипт
ожидания с перехваченным вызовом ОС. Она проверяет однократную попытку открытия, запасную ссылку,
продолжение после потери связи, завершение callback и отклонение небезопасных ссылок.

Подтверждение через настоящий Telegram на iPhone/Android и автоматический возврат фокуса не
проверялись. Браузер может потребовать разрешение на открытие приложения или ручную запасную кнопку.
