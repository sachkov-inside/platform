Все 16 проверок Home/Series/Reader/player shell прошли: горизонтального переполнения нет,
axe WCAG 2/2.1 A/AA не обнаружил serious/critical нарушений в проверяемой поверхности.
На Series дополнительно проверены реальные границы повёрнутых плиток внутри каждой обложки:
ни одна не выходит за рамку. Серия из двух материалов показывает две обложки.
На Reader проверены обычный незакреплённый верхний возврат, отсутствие повторного номера, корректная кнопка
«Дальше» и её отсутствие на последнем материале. 40 focused Storybook scenarios прошли,
включая Reader с текстом 200%. После финальной фиксации высоты кнопки просмотра
13 video scenarios повторно прошли; проверяется стабильность и ширины, и высоты.

Последнее уточнение владельца: обычная кнопка возврата всегда сверху; вне серии её нижний
повтор появляется только после прокрутки за верхнюю кнопку. В серии возвратом внизу служит
«Все материалы серии». Подпись переключателя видео — «Просмотрено» в обоих состояниях;
пустой кружок/галочка, оформление и aria-pressed обозначают состояние.
25 Reader/video stories и два live full-stack сценария переходов по сериям повторно прошли.
Новые проверки на 320/1440 px подтверждают короткую страницу без прокрутки и дубля,
нижний возврат после прокрутки длинной страницы, отсутствие закрепления и исчезновение
нижнего повтора при возврате наверх; axe/overflow проверки прошли.

Проверки автоматического плеера используют настоящий BFF/backend и подменяют только внешний
SDK Kinescope. Шесть desktop/mobile full-stack сценариев прошли: автоматическая загрузка
после allow, отсутствие iframe до allow и при deny, resume, retry, сохранение «Просмотрено»
при outage SDK, замена видео и переходы по выбранной серии. Эти проверки не доказывают
воспроизведение реального provider video. Итоговые команды,
результаты полного check, full-stack и CI текущего head записаны в PR #321.
Общий smoke обнаружил отдельную устаревшую проверку MCP tools/list — #339; для браузерных
сценариев использован локальный runner без этого несвязанного MCP assertion.

Backend API, права и оплата не менялись. Реальные Kinescope/Telegram acceptance и production
deployment здесь не выполнялись. Тестовая загрузка Kinescope в локальном контуре #186 ждёт
местоположения API-токена. Визуальное принятие и merge остаются за владельцем.
