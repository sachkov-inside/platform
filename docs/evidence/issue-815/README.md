# Issue 815 — скидка респондентам анкеты

Снимки историй Storybook на 390 и 1440 без горизонтальной прокрутки. Ники и коды выдуманные.

- `owner-link-issued-*` — владелец выдал личную одноразовую ссылку.
- `owner-imported-*` — итог загрузки колонки анкеты: только счётчики.
- `buyer-discount-*` — покупатель пришёл по ссылке, расчёт применил скидку.
- `buyer-rejected-*` — код израсходован или истёк: обычная цена и объяснение.
- `buyer-guest-*` — гость по ссылке: код сохранится после входа.
