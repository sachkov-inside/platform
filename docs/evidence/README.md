# Архив проверок

В старых отчётах, журналах и именах снимков прежний каталог компонентов обозначен как
`ui-catalog`. Это обозначение применяется к архивным командам, именам инструментов и путям
из журналов.

Исходные названия, журналы и команды доступны в [предыдущем Git-снимке](https://github.com/sachkov-inside/platform/tree/80464171b9ee57e7e22222ea63b4867fd1d34890/docs/evidence).
Для воспроизведения используй исходный снимок и ревизию, указанную в отчёте.
