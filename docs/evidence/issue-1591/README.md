# Reader: внедрение принятой панели A, #1591

Владелец принял вариант A на desktop и mobile, затем поручил внедрение, merge и закрытие
[#1591](https://github.com/sachkov-inside/platform/issues/1591). Внедрение назначено явным ответом
«да» на уточнение о переносе A в рабочий Reader.

[Прототип и решение владельца](https://github.com/sachkov-inside/platform/blob/9b4c7ce9347ca65f571e2b2265d90a3e48b8efbf/docs/evidence/issue-1591/README.md)
сохранены на отдельной ветке `prototype/1591-reader-actions`.
Эта ветка реализации не переносит демонстрационные действия в production.

Объём: Back, Save, Studied, Share слева, Next справа, повтор после текста. На широком экране
видны подписи, на узком второстепенные действия сокращаются до доступных значков.
Существующие обработчики закладок, изучения, отправки и навигации сохраняют свои контракты.
Боковая навигация, выбор главы, существующий мобильный dock и общий local stand не меняются.

Состояние: подготовка реализации. Production visual GO, независимое ревью и final-head CI
пока не получены. Принятие прототипа само по себе их не заменяет.
