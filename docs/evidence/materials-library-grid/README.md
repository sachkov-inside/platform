# Каталог «Материалы»: production visual gate (#1833)

Реализация принятого прототипа A2 (#1832). Снимки сделаны с кода PR #1834 на коммите `c88455279`
(изменён только тест `course-payload.spec.ts` после снимков).

## Storybook

`Pages/Product/Programme` → `MaterialLibrary` и `MaterialLibraryMobile`: обложки и узоры формата,
две главы, три материала вне программы (один закрыт), два изученных урока, зафиксированная дата
показа 2026-10-29.

- `storybook-new-order-desktop.png`, `storybook-new-order-phone.png`: порядок «Сначала новые»,
  группы «Новое», «Октябрь 2026 г.», «Сентябрь 2026 г.».
- `storybook-programme-order-desktop.png`, `storybook-programme-order-phone.png`: порядок
  «По программе», главы и «Вне программы», все материалы раскрыты.

## Живой маршрут

Production-сборка Web с тестовым backend браузерных тестов (`playwright.navigation.config.ts`),
продукт `reference-course`: обложек в данных нет, поэтому у всех карточек узоры формата. Общий
стенд был занят другой проверкой и не использовался.

- `route-catalogue-desktop.png`, `route-catalogue-phone.png`: `/products/reference-course/programme?part=materials`.
- `route-lesson-desktop.png`, `route-lesson-phone.png`: урок программы, открытый из каталога;
  хлебные крошки «Глава 1», подпись нижней панели «Глава 1 · 5/9» без переходов.

На 1440 и 390 px нет горизонтальной прокрутки и ошибок страницы. Axe в `course-payload.spec.ts`
проверяет каталог без нарушений на обеих ширинах.

## Отличия от A2

- У гайда и заметки на обложке только значок формата: времени чтения в данных нет.
- Закрытый материал показан текущим замком с размытием обложки.
- У заголовков групп нет счётчиков: каталог показывает материалы порциями, счётчик был бы неполным.
