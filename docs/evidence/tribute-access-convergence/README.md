# Локальная проверка #625

Это evidence промежуточного runtime, указанного в [provenance](provenance.json), с принятым настоящим Telegram consumer. Итоговые статусы и оставшиеся проверки находятся в [матрице 1–39](../../verification/subscription-access-convergence.json). Этот каталог сам по себе не означает закрытие всей задачи или разрешение production rollout.

[Desktop](tribute-desktop.json) проверяет реальный вход, pending registry, конечный тариф, чтение, сообщество, новый материал включённого Guide, выборочное расширение когорты, webhook/revoke/restore и восстановление потерянного ответа apply. [Mobile](tribute-mobile.json) проверяет тот же путь без отдельного расширения когорты. Снимки `desktop-account.png`, `mobile-account.png`, `desktop-owner.png`, `mobile-owner.png` сняты с реальных страниц; внешний Telegram/банк/Tribute — локальные doubles. Аутентификационные страницы и credentials не сохранялись.

[Курс desktop](course-desktop.json), [курс mobile](course-mobile.json), [существующий покупатель](existing-account.json) и [пересланная ссылка](forwarded-course.json) выполнены через принятый consumer и настоящий Platform runtime #625. Название synthetic курса содержит «64» как имя сохранённой fixture, а не как версия работающего Platform.

[Восстановленная пара](restored-pair.json) доказывает запуск двух приложений на восстановленных копиях PostgreSQL, чтение прав, точный replay evidence, настоящий `/access`, сохранение бизнес-данных после перезапуска и отказ несовместимых версий. Online backup не доказывает атомарный снимок двух баз. Внешнее состояние Telegram в этом тесте синтетическое; прежние реальные сообщения и права не менялись.

Воспроизведение требует отдельного synthetic stand по [runbook](../../runbooks/tribute-access-convergence.md), принятых пяти contract files и Telegram SHA из provenance. Для Tribute runner используется `node scripts/tribute-local-acceptance.mjs` на pinned Node с `TRIBUTE_PROOF_USER` (новый synthetic `64xxxxx`), `TRIBUTE_PROOF_OUTPUT`, `TRIBUTE_PROOF_OWNER_STATE`; `TRIBUTE_PROOF_MOBILE=true` выбирает mobile, `TRIBUTE_PROOF_NEGATIVE=unknown_period|nonpaid` — отрицательный путь. Private env содержит только локальные DATABASE_URL и synthetic Tribute ingress key; runner проверяет loopback endpoints. Не подставлять production credentials. Course runner принадлежит принятому Telegram repository; login screenshot в этой проверке отключён, runtime приложения не заменён.

[Временный источник](temporary-source.json) проверен через настоящий membership worker, evidence outbox и Platform ingress: реальный пятиминутный TTL, timeout, повторный member и защёлка после left. Policy явно относится к настроенной canonical legacy group. [Сбои источника](source-faults.json) используют нормализованные ответы внешнего Telegram adapter; это не самостоятельная проверка HTTP429 парсера или настоящих прав бота.
