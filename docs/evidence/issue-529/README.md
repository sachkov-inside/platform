# Путь гостя до покупки внутри платформы — #529

Дата: 2026-09-12. Фиксированная база: `eaf0acdf`.

Снимки сделаны сквозным прогоном `pnpm smoke:fullstack` на локальном стенде: PostgreSQL и object
storage из Compose-проекта `inside-platform`, API, MCP и Web этой ветки подняты host-процессами
на 3001, 3002 и 3000. Размеры совпадают с проектами Playwright: desktop 1440×1024 и mobile 390×844.

| `programme-guest-mobile-chromium.png` | То же на 390 px |

## Что проверено вживую

Сквозной прогон `guide product leads to the programme and the programme keeps the Reader return
position` зелёный на обоих размерах: страница продукта ведёт в программу одним действием, счётчика
«изучено N из M», процента и полосы прогресса нет, возврат из читалки приводит на ту же страницу
программы с `at=` и подсвеченной строкой, гость видит состав и замки, axe без нарушений.

Призыв к покупке проверен сквозными тестами `guest-home.spec.ts`, `material-reader.spec.ts` и
`link-preview.spec.ts`: на главной обе кнопки ведут на `/subscription` в той же вкладке, а у
закрытого материала внутри блока отказа нет ни одной внешней ссылки и ни одного `target="_blank"`.
На этом стенде руководство `platform-inside` продаётся отдельно, поэтому закрытый материал ведёт
на `/guides/platform-inside/buy`.

## Что не проверено здесь

- Вид каждого шага принимает владелец вручную: это условие родительской задачи #324.
- Оплата по-настоящему не проводится: приём денег остаётся выключенным.
- Выделенная строка продолжения и сводка «изучено N из M» на главной на снимках отсутствуют не
  по решению о структуре, а из-за отдельного дефекта: продолжение обучения сейчас не приходит ни
  на персональную главную, ни в программу. Воспроизводится на чистом `main`.
