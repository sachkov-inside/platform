# Мобильная навигация и заметки — #381

Проверено 7 сентября 2026 года. Production build Next.js использует локальный API и PostgreSQL.
Материалы демонстрационные. Физический iPhone и окончательная визуальная приёмка владельцем
остаются открытыми; production deploy не выполнялся.

## Поведение после обратной связи

Нижняя панель остаётся видимой. При холодном переходе выбранная вкладка и её loading UI
появляются до ответа маршрута; App Router продолжает владеть URL, историей и отменой перехода.
Старое содержимое временно скрыто и недоступно фокусу, но сохраняет свою высоту и прокрутку.
После ответа показываются данные выбранной страницы. Home также отдаёт streaming fallback
через Suspense, Account имеет route loading. [Описание streaming в Next.js](https://nextjs.org/docs/app/api-reference/file-conventions/loading).

ViewTransition и fade-out/fade-in страниц удалены по отзыву владельца. Анимация ограничена
элементами нижней панели. Поиск, фильтры и положение Базы знаний сохраняются, включая native Back.

В заметках уменьшены заголовки и показана дата публикации из существующей проекции API.
Последняя карточка при нескольких заметках служит размытым декоративным превью с кнопкой
«Все заметки». Она исключена из фокуса и дерева доступности. При одной заметке карточка
остаётся читаемой; при пустом списке сохранены объяснение и ссылка в каталог. Счётчик из
референса не добавлен: список на главной не является полным количеством заметок.

## Проверки

- Девять `test/e2e/mobile-navigation.spec.ts` проходят: URL/scroll, prefetch, быстрые клики,
  320/390/430 px, reduced motion/axe, ошибки/401, native Back, accountId и холодный переход.
- Общая проверка `test/support/immediate-mobile-navigation.ts` удерживает ответ RSC и требует
  показать выбранный раздел в пределах 500 ms до отпускания ответа. До изменения она падала;
  после изменения проходит и в dev, и в production build. Это проверка отсутствия ожидания сети,
  а не измерение производительности на физическом телефоне.
- Production suite `test/fullstack/mobile-navigation.spec.ts`: 7 passed, 3 desktop skips для
  исключительно мобильных сценариев. Реальные данные, переход в каталог заметок, дата,
  декоративное превью, отсутствие overflow и кадры без исчезновения панели проверены.
- Четыре Home stories проходят вместе с настроенным Storybook axe; дополнительное состояние
  NotesPreview проверяет доступность ссылки, исключение размытой карточки и дату.
- 12 проверок изменённых Library adapters проходят и сохраняют publishedAt.
- Итоговый набор проекта: `pnpm check`. Текущий результат CI и review хранится в PR #383.

## Границы

Первое получение самих данных требует сети; пользователь сразу видит выбранный раздел в
состоянии загрузки. Серверные правила доступа и контракты не изменены. Локальная проверка
не использует реальные Telegram credentials и не доказывает цвет внешних панелей Safari.
