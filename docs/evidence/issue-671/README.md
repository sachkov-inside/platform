# #671 — страница продукта из данных

Проверка требования «Скриншоты страницы AI-first и карточки на Главной до и после совпадают:
desktop и mobile, текст и анимация».

## Как снято

Снимки сделаны Playwright по локальному стенду `inside-platform` (`http://127.0.0.1:3000`),
страница `/guides/working-with-agents` и карточка продукта на Главной, два кадра каждый:

- `*-reduce.png` — с `prefers-reduced-motion: reduce`, поэтому анимация показывает одну и ту же
  сцену и кадры сравнимы построчно;
- `*-no-preference.png` — обычный режим: анимация живая, кадр зависит от момента съёмки.

Рядом лежит `*-text.txt` — весь видимый текст страницы и карточки на момент съёмки.

## before

Стенд на `main` 0e0676d2: текст страницы жил в коде web
(`apps/web/src/features/ai-first-guide/model/ai-first-guide.ts` и разметка
`ai-first-guide-view.tsx`), оформление выбиралось сравнением адреса.

## after

Стенд на ветке задачи после `pnpm local:product`: тот же текст приходит из описания продукта в
Inside Content (`guide.yaml`, ключ `page`), оформление выбирается полем `presentation`.
