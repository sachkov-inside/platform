# Возврат к месту чтения — #547

Снимки живого локального стенда: настоящий API, PostgreSQL и сохранённая история обучения
аккаунта. Сделаны при 1440×1024 и 390×844 на руководстве `demo-progress-series`, в котором из трёх
материалов изучен один.

- `*-home.png` — персональная главная. Карточка руководства зовёт продолжить и показывает
  «Продолжить · изучено 1 из 3». Соседнее руководство без истории показывает честное состояние
  начала: «Руководство · 2 материала».
- `*-programme.png` — программа руководства. Изученный материал отмечен галочкой, а место
  возврата выделено кольцом и несёт `aria-current="step"`. Текстовой подписи в строке маршрута
  нет: её убрал #441 вместе с прочими лишними статусами, и это решение остаётся в силе.

До починки обе поверхности показывали состояние начала при живой истории: ответ продолжения нёс
необъявленный ключ, и строгий разбор на стороне веба терял всё тело.

Снимки сняты на дереве, где к ветке этой задачи добавлены изменения #529: они приводят сквозные
проверки и адреса страниц руководства к текущей структуре и приезжают в `main` раньше. Это
состояние после мержа обеих задач.
