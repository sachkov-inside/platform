# Bento курса на планшете — #1374

При ширине 923 px широкие карточки занимали обе колонки, а соседние карточки — одну.
После правки десять тем идут в исходном порядке пятью парами одинаковой ширины.
На телефоне остаётся одна колонка, на широком экране — прежняя композиция из четырёх колонок.

## Проверка поведения

- Проверка геометрии живого лендинга при 923 × 1512 падала до правки и проходит после неё.
- Storybook `Pages/Product/AI Engineering/Tablet` проверяет одинаковую ширину и положение каждой пары.
  Эта проверка также падала до правки и проходит после неё.
- Storybook MCP `test-run` для `Mobile`, `Tablet` и `Desktop` проходит, включая проверку доступности.
- При ширинах 320, 390, 767, 768, 923, 1023, 1024 и 1440 px горизонтального переполнения страницы нет.
  Подписи иллюстраций помещаются в карточках на всех восьми ширинах.
