# Служебные надписи, задача #1715

[Задача](https://github.com/sachkov-inside/platform/issues/1715). Исходный commit: `d2d331363701c6c2a03539e5ab86212a4fc561b1`.

Меняются только надписи. Обработчики, переходы, согласия, сроки, суммы и права доступа сохраняются.
Полные юридические документы и учебные материалы в этот проход не входят.

## Словарь действий

- «Войти» или «Войти через Telegram», если действие сразу открывает Telegram.
- «Подключить Telegram» для подключения к аккаунту.
- «Почта» в формах, «Почта для чека» при покупке.
- «Получить код», «Отправить новый код», «Подтвердить почту».
- «Проверить статус» для повторного запроса оплаты, без создания новой покупки.
- Ошибка называет действие и следующий шаг. Коды обращения сохраняются.

## Обход экранов

Проверены источники маршрутов и их производственных компонентов. Состояния из каталога Storybook
используются для проверки действий и отображения. Обход исходников не означает вход под всеми ролями
на рабочем стенде или изменение настроек действующего сервиса авторизации.

| Раздел | Состояния и решение |
| --- | --- |
| Главная, темы, продукты, программа, поиск, карта | Загрузка, пустой результат, недоступность, неизвестный адрес. Убрана устаревшая ссылка на Базу знаний. Названия продуктов и авторский текст сохранены. |
| Вход и регистрация | Общий вход Logto по коду или Telegram; создание аккаунта использует тот же путь. Подсказка о данных не принимает условия заранее. Названия стандартных действий оставлены. |
| Telegram-вход | Ожидание, подтверждение, отмена, истёкшая и использованная ссылка, отключение, ошибка, восстановление связи. Перезапуск назван «Войти снова». |
| Первый вход | Новые и обновлённые условия, ожидание, ошибка принятия, новая редакция, завершённая сессия, недоступные документы. Возраст 14 лет, ссылки и принятие кнопкой сохранены. |

| Покупка, личная ссылка, возврат из банка | Недоступная продажа, условия, почта для чека, повтор после потери ответа, ожидание банка, ошибка, возврат, открытие доступа, чек. Суммы и условия покупки не менялись. |
| Принятые документы и cookies | Загрузка, пустой список, недоступность, история согласий, первое посещение и новая редакция cookies. «Понятно» остаётся скрытием уведомления. |

| Задания | Загрузка, закрытое задание, неизвестное задание, нет сдач, отправка, ошибка, новая версия. Подсказки формы приведены к обращению на «вы». |

Отдельного восстановления пароля нет: вход по коду без пароля. Повтор кода и просроченные ссылки
проверяются в существующих сценариях входа. Выход сохраняет существующие подписи и переходы.
