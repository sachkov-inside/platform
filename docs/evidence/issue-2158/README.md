# Сворачивание меню уроков, прототипы (#2158)

Задание владельца 2026-11-15: «сделай мне прототипы я посмотрю». Прототип:
`apps/web/src/features/library-discovery/ui/collapsible-lesson-menu-prototype.stories.tsx`, группа
историй `Prototypes/2158 Сворачивание меню уроков`. Только тестовые данные курса, продовый код этот
файл не импортирует.

Три варианта на широком экране (от 64rem):

1. **Узкая полоса.** На месте меню остаётся полоса с одним значком «Развернуть меню уроков» (имя в
   `aria-label` и подсказке `title`), урок прежней ширины (43rem) стоит по центру страницы.
2. **Кнопка «Программа» в шапке.** Меню скрывается целиком, кнопка «Программа» справа от хлебных
   крошек возвращает его. Урок прежней ширины по центру.
3. **Полоса, урок шире.** Как первый, но колонка урока растёт до 58rem.

Общее во всех вариантах: кнопка «Свернуть меню уроков» стоит в строке «Страница курса»; у кнопок есть
`aria-expanded` и `aria-controls`; после сворачивания фокус переходит на кнопку разворачивания и
обратно; выбор помнится в этом браузере (`localStorage`, ключ на вариант); сдвиг колонок анимируется
за 200 мс и без анимации при `prefers-reduced-motion`. Ниже 64rem всё как сейчас: меню спрятано в
нижнюю панель «Программа».

Проверено в headless Chromium на 1440, 1024 и 390 по ширине: без горизонтальной прокрутки, без ошибок
на странице, Enter сворачивает и разворачивает, фокус и `aria-expanded` верные. При открытии истории
сохранённый выбор сбрасывается, чтобы каждый показ начинался с раскрытого меню.

Правка владельца 2026-11-15: на свёрнутой полосе (варианты 1 и 3) убрана вертикальная подпись «Уроки
главы», она нечитаемая. Остался только значок разворачивания, полоса сжалась до одной кнопки.

Решение владельца: пока не принято.
