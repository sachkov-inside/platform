# AI Engineering — анимация первого экрана: бриф и покадровый план

Задача [#808](https://github.com/sachkov-inside/platform/issues/808). Метод взят из разбора
«How to build motion design studio with Opus 5.5» (Movez, 27.09.2026): кадр — чистая функция
времени, режиссёрский бриф и покадровый план до кода, пружины в замкнутой форме, критика
собственных кадров по контактным листам до показа.

## Решения владельца (30.09.2026)

- Анимация заменяет статичную обложку на первом экране курса, позже — карточку на Главной.
- Без персонажа-песца и без стандартных значков: всё рисуется кодом. Решение «значки только
  lucide» из #614 относилось к анимации AI-first и здесь не действует.
- Сюжет — ценности курса: AI-first разработка, работа с агентами, рост harness, разные задачи,
  релизы.
- Динамично и эффектно; мобильная версия важнее всего.

## Фильм в одну строку

Ты ставишь задачу — агент её выполняет — harness растёт ступенями — задач становится много,
а релизы идут один за другим.

## Вид

Тёмная сцена `#202124`, тёплый белый текст, один акцент — терракотовый `#c7461e` / `#ef6b3c`.
Шрифт — шрифт сайта. Агент — терракотовая точка с орбитой, а не персонаж. Никаких градиентов,
свечения, подписей по углам, «заголовка по центру» и «всё плавно появляется». Каждые 1–2 секунды
на сцене происходит новое. Мельчайший текст — 30 единиц при логической ширине 960, это около
11 px в колонке телефона 358 px.

## Покадровый план (16 с, цикл)

| Время | Сцена | Что происходит |
|---|---|---|
| 0.0–2.4 | AI-first | Слово «AI-first» входит крупно, под ним строка задачи набирается по буквам |
| 2.4–6.4 | Агент работает | Точка-агент проходит этапы «Спецификация → Задачи → Код → Проверка», каждый получает галочку; справа идут строки кода; штамп «тесты 24/24» |
| 6.4–10.4 | Harness растёт | Ступени AGENTS.md → skills → MCP → RAG → evals вырастают лестницей, агент поднимается по ним; рамка harness обводит лестницу |
| 10.4–14.6 | Много задач | Сетка задач, агенты закрывают их параллельно, счётчик растёт |
| 12.8–14.6 | Релизы | Линия релизов поднимается v1.0 → v1.4, последний — акцентный |
| 14.6–15.6 | Итог | Держим итоговый кадр (он же статичный кадр для reduced motion) |
| 15.6–16.0 | Шов | Затемнение в начальный кадр |

Смена сцен — уход вверх с затуханием, без перелёта одних объектов в другие.

## Воспроизведение

Пауза и продолжение — кнопкой. Вне экрана и в скрытой вкладке время стоит. С
`prefers-reduced-motion` показывается итоговый кадр, проигрывание — только по кнопке.

## Критика

Контактный лист: кадр на каждую секунду, ширины 960 и 358. Оценка 1–10: хук в первые 2 с,
читаемость на телефоне, качество движения, разнообразие, композиция, соответствие курсу.
Три худшие проблемы исправляются, пока все оценки не станут 8+. Журнал — ниже.

## Журнал критики

1. Первый прогон, около 5–6 из 10. Ступени harness перекрывали подписи, у смен сцен были
   мутные наложения, справа в 3–4 с пусто, галочки налезали на названия этапов.
2. Второй прогон, около 7. Harness стал башней: слои падают и встают друг на друга. Уход сцен
   короче, код появляется раньше, у счётчика задач правильный отступ.
3. Третий прогон, около 8 по всем критериям. Буквы «AI-first» влетают по одной, агент принимает
   задачу. Агенты задач стоят у счётчика, а карточку в работе обводит рамка, так что текст ничем
   не закрыт. На 358 px самый мелкий текст около 11 px.

Проверено на странице: время идёт, пауза останавливает кадр, с reduced motion кадр неподвижен.
Не проверено: физический телефон, скринридер, производительность на слабых устройствах.

## Вторая версия — одна форма (30.09.2026)

Замечания владельца к первой версии: надпись задачи выходила за рамку, темп спешил, приёмы
повторялись (одинаковые появляющиеся карточки), крупный заголовок «harness» лишний — нужно
показывать, как всё происходит. Референсы владельца: собственная запись карточки продукта и
видео @motion_conquest, @tdinh_me, @twoclipping, @verbove. Их общая грамматика: одна форма
перетекает из состояния в состояние и не обрывается, смену ведёт курсор, содержимое входит после
начала перетекания и уходит до следующего, числа досчитывают, графики рисуются, одно крупное
событие в кадре, спокойный темп около 2 секунд на состояние, минимальный фон, один акцент.

Покадровый план (20 с, цикл, последний кадр равен первому): плашка «AI Engineering» → поле
запроса «Добавь вход через GitHub», курсор нажимает «отправить» → кружок «агент изучает проект» →
карточка плана, шаги отмечаются → изменения и «PR #42 открыт» → проверки 24/24, курсор включает
merge → harness проекта, слои AGENTS.md, skills, MCP, RAG, evals встают сверху, версия растёт →
три агента параллельно → счётчик релизов и растущая линия → «Релиз v1.4 выпущен» → плашка.
Тёмная форма на тёплом светлом фоне сайта, персонажа и стандартных значков нет, курсор нарисован кодом.

Критика: первый круг — форма слишком долго пустая при перетекании, слои harness наезжали при
входе снизу, переключатель merge выходил за край, итоговый кадр до последнего слоя. Второй круг —
перетекание быстрее, содержимое раньше, слои падают сверху, полоса проверок выше, итоговый кадр
13.8 с. На 358 px все подписи читаются.

## Третья версия — эпизоды и взмахи (30.09.2026)

Замечания владельца: «PR открыт» появлялся слишком быстро; все переходы одинаково росли из
центра; стык цикла не плавный; результаты сменялись раньше, чем их успевали прочитать; нужно
больше содержания: harness проекта с пайплайном, роли агентов, спецификация, реализация фич,
CI/CD и деплой, мониторинг токенов.

Фильм 32 с из четырёх эпизодов. Внутри эпизода одна форма перетекает, между эпизодами карточки
меняются взмахом: уход влево или вверх, вход справа с поворотом или снизу. Внутри состояний
элементы прилетают с разных сторон. План: плашка → запрос → «агент изучает проект» | окно harness
проекта (AGENTS.md, skills, roles, pipeline.yaml, evals и пайплайн Спецификация → Задачи →
Реализация → Ревью → CI/CD → Deploy), курсор открывает roles/ → роли архитектора, разработчика и
ревьюера | спецификация → реализация трёх фич параллельно → изменения и «PR #42 открыт» в шапке |
CI/CD build → tests → deploy и «production обновлён» → мониторинг токенов, расхода и задержки →
релизы → «Релиз v1.4 выпущен» → плашка. Каждый результат держится около секунды.

Стык цикла: последний кадр совпадает с первым, текст плашки на стыке не гаснет, период пульса
делит длительность фильма; разница кадров 31.99 и 0 с — до 21/255 на 50 пикселях. Критика:
карточки ролей и подписи мониторинга выходили за края на 358 px — расширены и сокращены.
