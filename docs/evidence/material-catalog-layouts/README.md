# Каталог «Материалы» в несколько колонок: сравнение раскладок

Задание владельца 2026-10-29. Только прототип: production-код не менялся, вариант владелец ещё не выбрал.
Основа: `079987f03` (`origin/main`). Ветка: `prototype/materials-catalog-layouts`.
Story: `Prototypes/Material Catalog Layouts` (`Compare`, `CompareMobile`), файл
`apps/web/src/_pages/library-discovery/ui/material-catalog-layouts-prototype.stories.tsx`.

## Вопрос

Как показать библиотеку материалов продукта в несколько колонок, чтобы видео с обложками и тексты
без обложек стояли ровно, без перекоса, который даёт текущая двухколоночная лента
(`MaterialCard variant="feed"`).

## Варианты

- A, «Ровная сетка»: у каждой карточки картинка 16:9; без обложки рисуется узор с значком формата
  (существующий `ContentCoverImage`). Название и описание обрезаны до двух строк, подпись прижата вниз.
- B, «Полки по формату»: видео с обложками одной полкой, гайды и заметки другой, без картинок.
  Внутри полки все карточки одинаковые.
- C, «Мозаика»: колонки без строк; разная высота задумана, пустых мест нет. Текст без обложки
  показан цветной карточкой с полным описанием.
- D, «Плитки»: плотные одинаковые плитки с квадратной миниатюрой; у урока без обложки на
  миниатюре номер «глава.урок».

Общее для всех: поиск, формат, «Из программы» / «Вне программы», порядок «Сначала новые»
(группы по месяцам) или «По программе» (группы по главам, затем «Вне программы»), подпись
происхождения, отметка «Новое» и «изучено». Данные: 18 материалов примера, в том числе без обложек.
Рамка та же, что у страницы программы (`programme-frame`): основная колонка около 46 rem, поэтому
сетки здесь в две колонки; три колонки включаются, когда колонка шире 54 rem.
