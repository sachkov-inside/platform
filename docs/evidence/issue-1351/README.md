## Как работает самопроверка

Агент ученика получает требования через MCP и проверяет проект. Он показывает ученику полный
отчёт и запрашивает подтверждение точного содержимого. MCP сохраняет подтверждённый отчёт,
включая неуспешный результат. Повтор с прежним ключом `submissionKey` и неизменным содержимым
не создаёт новую попытку.

Все сохранённые отчёты агента считаются попытками. Итог определяется обязательными критериями
той версии задания, по которой ученик сдавал работу. История показывает сохранённые результаты.
Диалог агента и работа между проверками в историю не входят. Новую сессию можно рекомендовать,
но MCP не может подтвердить её независимость.

Имя берётся из профиля ученика или Telegram. Telegram-контакт берётся через приложение Telegram
по текущей подтверждённой привязке. Проверка отвязки выполняется повторно после получения контакта.
Если контакт недоступен, список остаётся доступен и сообщает об этом. Автор может оставить
необязательный комментарий. Этот комментарий доступен ученику на сайте и через MCP.

## Проверки и пределы

- Скрипт `apps/web/test/evidence/capture-task-submissions.mjs` снял 14 состояний Storybook на двух ширинах, всего 28 снимков.
  Переполнения по горизонтали и нарушений Axe нет. Результаты находятся в `storybook-checks.json`.
- Проверки навигации с тестовыми HTTP-ответами прошли на компьютере и телефоне: 16 сценариев. Они охватывают историю,
  возврат, черновики, сохранение, ошибки, отсутствие сдачи и ограничение доступа.
- Четыре сценария проверили сохранение отчёта через MCP и передачу комментария автора на сайт и в MCP ученика.
- Контракт получения Telegram-контакта проверен с настоящей отдельной базой Telegram.
  Внешний Telegram API заменён тестовым ответом. Работа с внешним Telegram API здесь не подтверждена.

Это результат подключения макета. Принятие макета не заменяет отдельное визуальное принятие
интерфейса на сайте. Перед завершением задачи нужны это принятие, зелёный `pnpm check`
и CI на окончательном коде. Выпуск платформы остаётся частью [#854](https://github.com/sachkov-inside/platform/issues/854).
