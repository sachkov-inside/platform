# Каталог «Материалы»: темы, полки и картинки без обложки

Задание владельца 2026-11-11. Только прототип: production-код не менялся.
Основа: `864e18525` (`origin/main`). Ветка: `prototype/materials-library-sections`.
Файлы в `apps/web/src/_pages/library-discovery/ui/`:

- `material-library-prototype-kit.tsx`: данные-примеры, рамка страницы, страница полок и
  переключатель вариантов;
- `material-library-sections-prototype.stories.tsx`: круг 1, `Prototypes/Material Library Sections`;
- `material-library-shelves-prototype.stories.tsx`: круг 2, `Prototypes/Material Library Shelves`;
- `material-library-covers-prototype.stories.tsx`: круг 3, `Prototypes/Material Library Covers`.

Данные: 22 материала, 3 главы, 6 тем, 8 материалов с обложкой. «Сегодня» в примере 2026-11-11.

## Вопрос

Материал, который не входит ни в одну главу (например, про дизайн с агентами), не должен
теряться в каталоге. Как разложить материалы курса и как показать материал без обложки.

## Круг 1: как раскладывать

- A, «Полки по темам»: у материала одна тема, страница из полок по темам и «Новое».
- B, «Подборки»: автор собирает упорядоченные подборки, ниже каталог по месяцам.
- C, «Фильтры»: один список, его сужают тема, формат, глава, статус и метки.
- D, «Разделы в боковой колонке»: темы и подборки слева под «Материалами».

Владелец выбрал A.

## Круг 2: видео и тексты

Описания карточек и тем убраны с обзора, чтобы сократить текст. Варианты: A1 видео карточками,
тексты строками; A2 только строки; A3 тексты плитками; A4 картинка у каждого.

Владелец выбрал A4: все материалы выглядят одинаково, картинка над названием.

## Круг 3: картинка материала без обложки

P1 цвет и знак темы; P2 узор материала; P3 лист с текстом; P4 картинка темы; P5 карточка ссылки.

## Решения владельца (2026-11-12)

- P5: тёмная карточка, как картинка превью ссылки, но без логотипа и имени сайта.
- Подпись и название посередине по высоте, текст прижат влево, оранжевая черта внизу.
- Подпись называет формат: «Гайд», «Видео», «Заметка».
- Под карточкой без обложки название не повторяется.
- «Новое» держит материалы последних 7 дней, сначала свежие. Свежий материал остаётся и на полке
  своей темы.
- У каждого курса свои темы. Порядок тем задаёт автор; пустая тема не показывается.
- Внутри полки сначала уроки программы по главе и уроку, затем материалы вне программы, свежие
  первыми. Полка показывает все материалы темы и листается вбок; «Все N» открывает тему сеткой.
- Переключатель «Всё / Видео / Тексты» остаётся.
