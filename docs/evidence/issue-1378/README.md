# #1378 — прототип каталога артефактов

Это подготовительный Storybook-прототип, а не реализация задачи в Platform.
Код остаётся на `prototype/1378-artifact-resources`; production-маршруты его не импортируют.
Данные синтетические. Backend, ContentAccess, редактор и импорт не подключены.

## Решения владельца

В этой сессии владелец принял упорядоченный набор текстов, файлов и внешних ссылок.
К отдельному ресурсу можно приложить промпт применения; скилл может содержать несколько файлов.
Обновление заменяет содержимое без доступной читателю истории. Страница артефактов входит в объём задачи.
Ссылка из материала должна открывать актуальный объект каталога, а не копию ресурсов в уроке.

В production сохраняется существующая защита ContentAccess. Технический счётчик доставки
потребуется сохранить для проверки актуальности адресов; он не создаёт пользовательскую историю.
Это план интеграции, а не поведение данного прототипа.

## Компактный каталог в навигации курса

Владелец отклонил отдельную широкую страницу и крупные элементы, похожие на материалы.
Текущий вариант показывает короткие строки: значок, название, вид и число ресурсов.
Описание, дата обновления и содержимое появляются после нажатия в окне просмотра.
Ресурсы выбираются внутри окна; доступны копирование текста, скачивание файла, ZIP и внешние ссылки.
Закрытый артефакт открывает только описание доступа без ресурсов.

Сверка с `origin/main` не обнаружила расхождения общей оболочки и навигации Storybook.
Расхождение создавал старый прототип. Теперь production-программа и прототип используют общий
`ProductProgrammeFrame`. Production-программа сохраняет прежнюю разметку, оплату и прогресс.
Прототип использует настоящий `SeriesJourneyControls`: разделы «Программа», «Материалы», «Артефакты»,
навигацию слева на компьютере и снизу на телефоне. Три материала в прототипе синтетические.

## Воспроизведение

Из этого worktree: `pnpm storybook --port 6009 --ci`.
В каталоге: `Prototypes/Artifacts/Catalog and preview`.
Story `Catalog` открывает раздел артефактов через настоящий элемент навигации.
Переключатель старых композиций удалён по решению владельца о компактном каталоге с окном.

## Актуальные снимки

- `compact-course-desktop.png`, `compact-course-mobile.png`: каталог внутри курса.
- `compact-preview-desktop.png`, `compact-preview-mobile.png`: окно содержимого.
- `compact-lesson-mobile.png`: компактная ссылка из урока.
- `compact-preview-long-text-end.png`: доступный конец промпта при шрифте 200%.

Снимки без префикса `compact-` сохраняют историю отклонённого варианта; они не описывают текущий интерфейс.

## Проверка прототипа

Chromium проверил переходы между тремя разделами, поиск, выбор файла, закрытие Escape,
возврат фокуса и сохранение прокрутки урока. Закрытый пример не раскрывает ресурсы.
Содержимое буфера совпало с исходным текстом предпросмотра.
Проверка горизонтального переполнения прошла на 1440 и 390 пикселях.
Последняя строка промпта из 4412 символов доступна при мобильном размере и корневом шрифте 200%.
Девять текущих Storybook-сценариев прошли проверки, включая доступность.
TypeScript, focused oxlint, Prettier и web guardrails прошли.
Ранее скачанные `project-map.txt` и ZIP совпали с исходными байтами fixture; ресурсы и механизм скачивания не изменены.

Полная задача #1378 остаётся открытой. Production-интеграция, поддержка Markdown и изображений,
импорт, редактор и проверки доступа предстоят после приёмки прототипа.
