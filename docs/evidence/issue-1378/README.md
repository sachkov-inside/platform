# #1378 — прототип каталога артефактов

Это подготовительный Storybook-прототип, а не реализация задачи в Platform.
Код остаётся на `prototype/1378-artifact-resources`; production-маршруты его не импортируют.
Данные синтетические. Backend, ContentAccess, редактор и импорт не подключены.

## Решения владельца

В этой сессии владелец принял упорядоченный набор текстов, файлов и внешних ссылок.
К отдельному ресурсу можно приложить промпт применения; скилл может содержать несколько файлов.
Обновление заменяет содержимое без доступной читателю истории. Страница артефактов входит в объём задачи.
Ссылка из материала должна открывать актуальный объект каталога, а не копию ресурсов в уроке.

В production сохраняется существующая защита ContentAccess. Технический счётчик доставки
потребуется сохранить для проверки актуальности адресов; он не создаёт пользовательскую историю.
Это план интеграции, а не поведение данного прототипа.

## Варианты для приёмки

- **Список и окно**: поиск и фильтр вида; артефакт открывается поверх каталога или урока.
- **Открытые разделы**: состав и содержимое каждого артефакта читаются прямо в каталоге.
- **Список и просмотр**: выбор слева и содержимое справа на компьютере; на телефоне открывается окно.

Прототип использует существующую публичную оболочку, токены и Button. Окно на телефоне
занимает экран, на компьютере — центральную область. Кнопка закрытия и Escape закрывают окно.
У текстового ресурса есть копирование и скачивание; у скилла — выбор файла и ZIP-набор.
Репозиторий показывает отдельный промпт применения. Файл `.drawio` показывает состояние без предпросмотра.
Закрытый пример не содержит ресурсов. Есть состояния загрузки, ошибки, пустого каталога и пустого поиска.

## Воспроизведение

Из этого worktree: `pnpm storybook --port 6009 --ci`.
В каталоге: `Prototypes/Artifacts/Catalog and preview`.
Кнопка «Варианты прототипа» раскрывает переключатель внизу. По умолчанию он свёрнут и не закрывает содержимое. Переключатель меняет вариант; параметр `variant=0`, `variant=1` или `variant=2`
в URL iframe сохраняет выбор после перезагрузки. Стрелки клавиатуры также переключают вариант,
если фокус не находится в поле ввода или окне просмотра.

## Подготовленные снимки

- `catalog-desktop.png`, `catalog-mobile.png`: список.
- `open-sections-desktop.png`: открытые разделы.
- `split-view-desktop.png`: список с областью просмотра.

## Проверка прототипа

Локальный браузерный проход в Chromium проверил поиск, фильтр, выбор файла, закрытие Escape
и возврат фокуса. После закрытия просмотра урока `scrollY` сохранился: 150 до и 150 после.
Tab не переводил фокус на элементы фоновой страницы; переход фокуса к интерфейсу браузера допустим.
Проверка `scrollWidth <= clientWidth` прошла на 1440 и 390 пикселях, а также в мобильном
просмотре с корневым шрифтом 200%. Это проверка этого сценария, а не всех сочетаний устройств.
Промпт содержит 4412 символов. Последняя строка доступна после прокрутки на экране 390 пикселей
при корневом шрифте 200%. Переключатель вариантов по умолчанию не перекрывает каталог.
Содержимое буфера после копирования совпало с `textContent` предпросмотра.
Скачанный `project-map.txt` совпал с UTF-8 исходного fixture; ZIP содержит точные `SKILL.md` и `checklist.md`.

Полная задача #1378 остаётся открытой. Production-интеграция, поддержка Markdown и изображений,
импорт, редактор и проверки доступа предстоят после приёмки прототипа.
