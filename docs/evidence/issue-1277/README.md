# Квиз в Reader: выбор прототипа #1277

Part of [#940](https://github.com/sachkov-inside/platform/issues/940).

## Выбор

| Вариант | Что меняется | Компромисс |
| --- | --- | --- |
| A — встроенный блок, рекомендация | Вопрос и ответы видны в потоке чтения. Объяснение появляется ниже. | Квиз занимает место даже без ответа. |
| B — раскрываемая проверка | Ученик сам раскрывает вопрос. После ответа можно свернуть весь блок. | Начально скрытый вопрос проще пропустить. |
| C — разворот вопроса | Вопрос слева, ответы справа. Результат заменяет ответы; на телефоне колонки идут друг за другом. | Узкая колонка удлиняет ответы на desktop. |

Рекомендую A: вопрос заметен, объяснение остаётся рядом с выбранным ответом, чтение продолжается.
Во всех вариантах есть повтор ответа, «Не знаю» без ошибки, все объяснения и ссылка на раздел.

## Проверка

[verification.json](verification.json) фиксирует 30 сочетаний: три варианта, два размера и пять состояний.
В этой матрице axe не нашёл нарушений в `[data-story-content]`, области проверки проекта.
Проверены Enter/Space, повтор с возвратом фокуса к первому ответу, разборы, ссылка на раздел,
параметр варианта после перезагрузки и отсутствие горизонтального переполнения.
Это автоматическая проверка и просмотр снимков; ручной прогон VoiceOver не выполнялся.

`pnpm check` завершился с exit code 0 на коде `b559a1f5`. После исправлений повторно прошли web typecheck и lint.
Сборка Storybook прошла. MCP `test-run` с a11y прошёл для пяти stories: Playground, Correct, Incorrect, DontKnow, AllExplanations. Production-код и реальные данные не менялись.
