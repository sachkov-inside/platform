# Дорожная карта курса на вкладке «Программа», вариант A

Задание владельца 2026-11-13. Прототип: `apps/web/src/_pages/library-discovery/ui/course-roadmap-prototype.stories.tsx`,
story `Prototypes/Course Roadmap`. Только тестовые данные, продовый код этот файл не импортирует.

Вопрос: ученики спрашивают, какие темы ещё выйдут в курсе. Владелец выбрал из четырёх HTML-набросков
вариант A «Список с метками» и попросил добавить «Обновлено …» из варианта D.

Что показывает прототип:

- в шапке программы строка «Готово 2 главы», «Обновлено 13 ноября» и полоска по главам (у главы в
  работе закрашена доля готовых уроков);
- главы разбиты на три части с заголовками;
- готовая глава без метки, свёрнута, показывает «Изучено X из N» и раскрывается в обычные строки уроков;
- глава в работе раскрыта: готовые уроки как обычно, будущие серые с пунктирной рамкой, «Пишется» или
  «Скоро», без ссылки;
- будущая глава: название, метка «В планах», строка результата и свёрнутые темы чипами.

Второй проход владельца 2026-11-13: убраны «1 пишется · 9 в планах», метки «Готово» и «Следующая»,
число уроков у готовой главы. Будущих глав пять:

1. Тестирование, проверки, фидбэк и evals.
2. Практика: разработка реального проекта с агентами.
3. Инфраструктура, CI/CD и деплой с агентами.
4. Существующий проект и процесс команды с агентами (тема «Безопасность: права и песочницы для агентов»).
5. Разработка агентов-помощников и встраивание их в продукты (LLM, tool calling, RAG, память,
   безопасность).

Главы «Как устроены LLM и агенты», «Свой агент в продукте», «RAG», «Безопасность агентов» и «Качество
AI-функций» убраны, их содержание стало темами.

Состояния: `Default`, `DefaultMobile`, `Expanded` и `ExpandedMobile` (раскрыта готовая глава и темы
первой будущей главы), `AllDone`, `NoPlanned`. Названия уроков двух готовых глав и строки результата будущих глав
условные.

Поля для боевой версии в presentation-контракте программы (сейчас их нет, экспорт не менялся):

- глава: статус `done | writing | planned`, строка результата, темы;
- урок: статус для неопубликованных уроков главы в работе `writing | soon` и его название;
- часть: название и порядок, глава ссылается на часть;
- программа: дата обновления дорожной карты.
