# Внешняя проверка production и эксплуатационные сигналы

Часть [#854](https://github.com/sachkov-inside/platform/issues/854), исправление
[#1385](https://github.com/sachkov-inside/platform/issues/1385).

## Найденный отказ

[Плановый запуск 38229931385](https://github.com/sachkov-inside/platform/actions/runs/38229931385)
проверял старый Web на `inside.sachkov.dev` и получил ожидаемый HTTP 302.
Workflow завершился успешно, хотя журнал перечислил отказ. Код сохранял `alerted: true`
до доставки, поэтому недоставленное сообщение подавляло следующие сигналы.

## Исправление и проверка

Web проверяется на `https://sachkov.dev/`; API потоков остаётся на
`https://inside.sachkov.dev/billing/cohorts`; discovery остаётся на `auth.sachkov.dev`.
TLS проверяется для всех трёх адресов. Проверка не следует редиректам.

Подтверждение доставки сохраняется после успешного ответа. Неудачная доставка отказа
или восстановления повторяется в следующем запуске и завершает workflow с ошибкой.
Успешно доставленный сигнал подавляется до восстановления.

Три регрессионных сценария сначала дали отказ: старый адрес, потерянный сигнал и
неудачная доставка восстановления. После исправления 25 проверок monitor/watchdog прошли.
Проверка запасной почты воспроизводит недоступный Telegram, отказ и восстановление.
Тесты используют сетевые и процессные doubles; настоящие сообщения не отправлялись.

Локальная внешняя проба рабочего исправления 12.10.2026 в 18:42:01 UTC получила пустой
список отказов. Она читала production и проверила три TLS-сертификата. Это не запуск
workflow после merge. Версии приложений остались Platform v34 и Telegram v16,
Source `bdae0c8284fe284569453183a40d567c2b099ec4`.

retention завершилась в 16:02:20 UTC и оставалась свежей. Доступно 1 443 614 720 байт памяти
и 12 819 501 056 байт диска. Сдачи включены в API/MCP; Telegram marketing выключен.

Отдельный бот сигналов, запасная почта и repository secrets `MONITOR_*` ещё не настроены.
Фактическая доставка владельцу и его GitHub notification preferences не проверены.

[отчётом #1356](../issue-1356/README.md). Восстановление Object Storage не проверялось.
Platform v33 несовместима с текущей схемой; требуется исправляющий выпуск.
