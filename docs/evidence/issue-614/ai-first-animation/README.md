# AI-first разработка — анимация карточки: передача на внедрение

Статус на 13.09.2026: владелец принял направление прототипа после четырёх кругов правок.
Это не финальное визуальное GO и не публикация. Внедрение делает отдельная сессия по этому
документу и по `docs/agents/frontend-delivery.md`. Продолжение #614, рядом с
`ai-first-guide-iteration.md`.

Источник правды — `index.html` в этой папке. Копия для просмотра вне репозитория:
`/Users/dev/Work/Inbox/ai-first-guide-animation/index.html`; при расхождении верна версия в репозитории.

## Как посмотреть

Открыть `index.html` в браузере, сервер не нужен. Вкладки показывают три реальных слота:
карточка на Главной (desktop, копия текущей вёрстки), hero страницы руководства, мобильная карточка 390 px.
Под карточкой: «Повторить», «Пауза», «Зациклить», кнопки сцен 1–5.

Параметры адреса: `?frame=home|guide|mobile`, `?scene=N` — старт с N-й сцены, `?loop=0` — один прогон,
`?static` — статичный кадр без движения, `?static&scene=N` — статичный кадр N-й сцены.

Кадры-эталоны рядом: `scene-1-agents-1440.png` … `scene-5-release-1440.png`, `mobile-card-390.png`.
Скрипты `shoot.mjs` и `shoot-transitions.mjs` снимают кадры через Playwright из `apps/web`:

```bash
cd apps/web && node ../../docs/evidence/issue-614/ai-first-animation/shoot.mjs
```

Снимки пишутся во временную папку системы (путь печатается в конце), в репозиторий ничего не
добавляется; другую папку задаёт переменная `SHOTS_DIR`. `shoot-transitions.mjs` принимает список
границ сцен в миллисекундах, например `node … shoot-transitions.mjs 4000,7600`.

## Решения владельца, которые нельзя терять

- Название и кнопка живут в карточке и не двигаются; сцена занимает только слот иллюстрации.
- Сцена проектируется под реальный слот: Home ≈ 512×432, hero руководства ≈ 480×387,
  мобильная карточка 358×~230. Слот примерно 1.2:1; отдельная карточка 4:3 со своим
  заголовком отклонена.
- Иконки только lucide (в проекте `lucide-react`), никаких самодельных SVG.
- Вместо ветвления функций — харнес и пайплайн; порядок сцен: контекст → харнес → архитектура →
  проверка → выпуск. Темп быстрее прежнего примерно в полтора раза.
- Перелёты объектов между сценами (морфинг) отклонены: «как раньше, необязательно чтобы одни
  объекты в другие превращались». Код перелётов в `index.html` остался под флагом
  `USE_MORPHS = false`; переносить его в проект не нужно.
- Гейты «ты» на линии пайплайна убраны. Бейдж задачи без иконки, с нормальными отступами.
- Мобильная раскладка Главной по референсу владельца: сверху eyebrow «Руководство», заголовок и
  подзаголовок, ниже тёмная карточка с анимацией и подвалом внутри (число материалов, стрелка,
  «Открыть»), описание уже под карточкой. См. вкладку «Мобильный» в прототипе и `mobile-card-390.png`.
- Практики движения взяты из `vertical-content` (кривые Carbon, стаггер 160 мс, приход с инерцией и
  смазом, уход сцены с размытием, стеклянные панели, сетка фона). Значения уже в CSS прототипа.

## Как переносить

Компонент в `apps/web/src/features/ai-first-guide/ui/`, клиентский (`"use client"`), например
`AiFirstProcessArtwork` с интерфейсом:

- `mode: "animated" | "static"`, `scene?: 1 | 2 | 3 | 4 | 5` для статичного режима,
  `loop?: boolean` (по умолчанию `false`, см. открытые вопросы);
- корень — контейнер `position: relative; container-type: inline-size; height: 100%`, сцена
  внутри `position: absolute; inset: 0`; размер задаёт родитель;
- `role="img"` с `aria-label` как в прототипе; всё внутри `aria-hidden`.

Разметка: содержимое `<template id="stage-template">` из `index.html` переводится в JSX один в один.
Символы `<use href="#i-…">` заменяются компонентами `lucide-react`:

| символ | lucide-react |
|---|---|
| i-file | FileText |
| i-user | User |
| i-user-check | UserCheck |
| i-arrow-up | ArrowUp |
| i-arrow-right | ArrowRight |
| i-window | AppWindow |
| i-braces | Braces |
| i-db | Database |
| i-list | List |
| i-list-checks | ListChecks |
| i-sparkles | Sparkles |
| i-check | Check |
| i-x | X |
| i-package | Package |
| i-git-branch | GitBranch |
| i-search | Search |
| i-code | Code |
| i-eye | Eye |
| i-activity | Activity |
| i-scroll | ScrollText |
| i-server | Server |
| i-layers | Layers |

Символ `i-bot` в текущей версии не используется.

Стили: блок CSS от `/* ---------- Сцена: подстраивается под контейнер */` до конца `@media
(prefers-reduced-motion)` переносится в `ai-first-artwork.css` почти без изменений. Стили рамок
страницы (`.home-guide`, `.ai-guide-hero`, `.phone`, `.tabs`, `.controls`) не переносятся — это
копии реальных страниц для просмотра. Токены `--cover-ink`, `--cover-ink-foreground`,
`--cover-mint-foreground`, `--font-body`, `--font-utility` уже есть в `app/globals.css`;
акценты `--accent`, `--mint`, `--coral`, `--lavender`, `--amber` и кривые `--ease-*` объявить в
области компонента, а не глобально. Правила `.stage-morph*`, `.morph-ghost*`, `.is-morph-*`
можно не переносить.

Логика: в прототипе это функция `mount()` — часы на `requestAnimationFrame`, переключение
`data-scene` и классов `is-active` / `is-leaving`, набор текста по часам сцены (`.type` с
`data-t` и `data-speed`), сегменты прогресса с `--d`. В React это `useEffect` с рефами и тем же
кодом; состояние React для посимвольного набора не нужно. Дополнительно для сайта:
останавливать часы, когда вкладка скрыта (`visibilitychange`) и когда карточка вне экрана
(`IntersectionObserver`); при `prefers-reduced-motion: reduce` не запускать часы и показать
статичную сцену 5 (в прототипе класс `is-static` обнуляет длительности и задержки). Первый
серверный рендер без активной сцены, запуск в эффекте — так не будет расхождения гидрации.
