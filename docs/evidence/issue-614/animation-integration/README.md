## Реализация

`AiFirstProcessArtwork` переносит сценическую разметку, иконки lucide, геометрию и задержки
из [принятой передачи](../ai-first-animation/README.md). Морфинг исключён. CSS ограничен
префиксом `.ai-process-artwork`, SVG gradient получает уникальный React id на каждый экземпляр.
Размер задаёт родитель. В hero 480/387, в мобильной главной 358/230.

Часы на requestAnimationFrame, DOM refs для текста и сцены. Один прогон 18,2 секунды плюс 1,2 секунды
удержания. Скрытая вкладка и выход за экран приостанавливают часы и CSS-анимации, включая переход
свечения. Reduced motion не запускает часы и показывает статичную сцену 5. Серверный HTML не
содержит активной сцены. В разделах страницы статичные сцены 2/3/5.

При переносе обнаружено выпадение корневых CSS-деклараций из вложенного блока со сценами:
фон растягивался до viewport. Стили развёрнуты в плоские селекторы, контейнер имеет явную позицию.
Истории теперь проверяют совпадение границ сцены и её родителя, включая ненулевую высоту.
