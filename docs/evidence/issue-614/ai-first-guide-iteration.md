# AI-first разработка — итерация 13.09.2026

Владелец изменил акцент с создания приложения на инженерный AI-first процесс, практики production
и развитие навыков разработчика. Страница и главная карточка оформлены под эту позицию.
Это локальная итерация для просмотра, не финальная приёмка и не публикация в production.

## Авторский источник и содержание

Inside Content: `docs/guides/ai-developer-positioning.md`, `guides/01. AI-first разработка/guide.yaml`.
Уточнение позиции записано обратно в описание продукта и summary руководства. Состав не менялся.
Platform хранит редакционную версию описания страницы в `features/ai-first-guide` и
`library-discovery/ui/ai-first-guide-view.tsx`. Подробная программа и доступ приходят через обычный каталог.

В уже работающую изолированную БД просмотра перенесены 20 глав и три авторских черновика:

- `how-agent-executes-task` — «Как агент выполняет задачу»;
- `configure-agent-workflow-and-design-feature` — «Выбери первую фичу и согласуй требования»;
- `how-to-review-agent-work` — «Как проверять работу агента».

Тексты сохранены через Materials application interface, а не прямой записью body в БД. Перенесены
заголовки, выделения, таблицы, код, промпты и варианты учебного/своего проекта; служебные направления
для будущих иллюстраций не входят в читательскую версию. Обложки материалов пока используют общий
fallback; это не готовый комплект для внешней публикации. Три текста открыты только в локальном
просмотре; это не решение о коммерческом доступе. Остальные главы показываются как готовящиеся.
Дополнительные материалы из `supplementary_materials` в эту ограниченную выборку не переносились.

## Просмотр

Страница `/guides/working-with-agents`, затем «Открыть программу», затем любой из трёх материалов.
Главная закреплена на этом руководстве. Анимация — три сцены за 4,8 секунды, однократно;
reduced motion сразу показывает последнюю. Сцены иллюстрируют программу, без живой телеметрии.

Коммерческие условия сопровождения, цена и полный состав запуска остаются открытыми.
CI и общий финальный прогон не являются воротами текущей итерации по указанию владельца.

## Уплотнение программы по отзыву владельца

Программа получила компактную плашку руководства с количеством глав и материалов. Для вошедшего
читателя сверху показан прогресс, для гостя он не выдумывается. Под прогресс зарезервировано место,
поэтому его загрузка не сдвигает уроки. На узком экране с увеличенным текстом обложка переносится
над названием. Строки уроков больше не содержат описаний, обложек и результатов обучения;
сохранены название, номер или отметка изучения, время видео, доступ и продолжение текущего урока.

«Программа», «Дополнительно» и «Артефакты» доступны всегда. Пустые разделы объясняют назначение;
ошибка артефактов показывается в своём табе. Состав и правила доступа не менялись.

Локальная проверка: реальные маршруты на 390 и 1440 px, переключение табов, 34 Storybook-сценария
программы (включая 320 px с текстом 200%), typecheck и documentation contract. Общий CI не ожидался.
Владелец готовит новую анимацию отдельно; предложен сюжет от контекста и архитектуры через
разработку функций и проверку к выпуску и эксплуатации.

### Следующее уточнение: номера и превью

Номер остаётся внутри карточки с подписью «урок», отметка изучения вынесена вправо. Текущий урок
имеет широкое действие «Продолжить». Главы обозначены простой цифрой без линий между ними.
Имеющаяся обложка отображается небольшой миниатюрой 16:9; для узкой строки приоритет у названия.
В Storybook добавлены сравнимые варианты MultipleLessonsWithPreviews / WithoutPreviews / Desktop:
3 демонстрационные главы по 4, 3 и 3 урока, 3 изученных и четвёртый текущий. Эти примеры не меняют
состав реального руководства. 37 сценариев программы прошли локально.

Владелец выбрал версию с превью: миниатюры теперь квадратные, 56 px, вертикальные отступы
карточки уменьшены до 8 px. Без авторской обложки показывается общий fallback. Номера глав убраны.
Вариант WithoutPreviews заменён на WithFallbackPreviews для проверки уроков без загруженной обложки.

### Пробные уроки

Локальный сценарий по указанию владельца: первые 3 материала руководства имеют `access=free`,
остальные 3 опубликованных — `membership`. Изменения проведены через Materials authoring,
исходники inside-content не менялись. В полной программе гостю видны все названия и главы:
бесплатные уроки помечены, превью закрытых размыты с замком. CTA «Посмотреть бесплатные уроки»
ведёт в полную программу. Доступ к полному тексту четвёртого урока проверен прямым открытием Reader.
Это сценарий локального просмотра, не определение окончательной цены и условий покупки.

### Покупка руководства вместо подписки

Убран fallback к подписке из программы и закрытого Reader. Программа больше не запрашивает
каталог подписки ради приглашения. При закрытых уроках верхняя плашка содержит
«Оплатить руководство» → `/guides/:slug/buy`; при полном доступе кнопки нет. Световой блик
проходит дважды за 4 секунды вместе с задержкой, затем останавливается; reduced motion
отключает движение. Пока нет опубликованной цены, страница покупки показывает готовящиеся условия,
не выдумывает сумму и не предлагает подписку. Цена и действительная оплата в этой итерации не настраивались.

## 13.09.2026 — результат практикума и спокойный цикл

Уточнены четыре группы аудитории: основы программирования нужны до старта,
опытным предлагается надёжный пайплайн, работающим с AI — сверка лучших практик.
Результат: довести проект до продакшена и самостоятельно развивать его с агентами.
Карточки результата объединены с пояснениями и наглядными итогами. Три больших
секции, повторявшие программу, убраны; темы собраны в одном обзоре.

Владелец явно изменил прежнее ограничение одного прогона: теперь цикл включён.
Часы сцен, набор текста, CSS durations и delays замедлены единым коэффициентом
1,25; полный цикл — 24,25 секунды. Reduced motion и пауза вне экрана сохранены.
Исторический HTML-прототип остаётся свидетельством прежней принятой версии.
