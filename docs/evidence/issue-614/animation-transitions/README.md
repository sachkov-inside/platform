# Плавная смена сцен — 14.09.2026

По замечанию владельца исправлен резкий переход, особенно заметный между проверкой и релизом.
Продолжение [Platform #616](https://github.com/sachkov-inside/platform/issues/616).

У выходной CSS-анимации не было начального keyframe: после замены входной анимации
базовый `opacity: 0` мог стать исходным значением. Теперь выход начинается явно с `opacity: 1`.
Вход и выход перекрываются на 800 ms реального времени (640 ms × time scale 1.25), без
сжатия до 92% и размытия 7 px. Остаётся небольшой сдвиг 6 px. Длительность задаётся одной
константой для CSS и часов удаления уходящей сцены. Сюжет, действия, цикл 24.25 s прежние.

перехода 4 → 5; сцена не переключалась вручную и анимации не отключались.
