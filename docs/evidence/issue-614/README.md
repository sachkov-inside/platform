# Главная: руководство и общая лента

Снимки реального Next-приложения из локального full-stack smoke, демо-данные PostgreSQL.
Основной стенд при проверке не перезапускался. Это свидетельство локального поведения,
не проверка production или credentialed Kinescope.

- [Главная 1440×1024](home-1440.png)
- [Главная 390×844](home-390.png)
- [Лента заметок 390×844](feed-390.png)

Программа не импортировалась: авторский закреп — «Demo · Релиз своего проекта».
Проверены поиск/формат/возврат/подгрузка, короткая бесплатная заметка, закрытое содержание,
продолжение руководства и видео в профиле, разделение аккаунтов и reduced motion,
axe и перенос при 200% тексте. Сквозной запуск: 37 passed, 3 conditional desktop skips.
Отдельные SQL integration проверки охватывают актуальную версию excerpt и смену доступа.

Владелец выбрал одну колонку после сравнения вариантов. Итоговое визуальное принятие
и merge требуют отдельного решения; эти снимки не подменяют его.

## Уточнение после просмотра владельцем

Актуальная лента: [1440×1024](feed-refined-1440.png), [390×844](feed-refined-390.png).
Все обложки 16:9, ширина до 28rem, центрированы; desktop колонка 42rem. Рамки отклонены владельцем,
в итоговом варианте только горизонтальные разделители. Видимый заголовок и счётчик убраны,
поиск компактный. Дублирующая строка закрытого доступа убрана; состав ленты пока не менялся.
Демонстрация руководства проигрывается один раз за 4,8 секунды, без кнопки паузы.

Повторный проход реального API/DB/Web: 6 сценариев на 1440/390 — поиск RU/EN, форматы, возврат,
подгрузка и отсутствие закрытого текста. SQL integration дополнительно проверяет ссылку редактора
под подписью, её изменение/удаление и закрытие доступа. Сторонние OpenGraph данные не загружаются:
превью использует авторскую обложку и домен. Полный редизайн руководства и роль бесплатной
подборки ожидают авторского содержания и решения владельца.
