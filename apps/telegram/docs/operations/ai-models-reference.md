# Загрузка Справочника «ИИ-моделей»

Команда `ai-models-reference-import` загружает Справочник раздела «ИИ-модели» в базу бота из
одного файла JSON. Формат файла описан в [контракте Справочника](../integrations/ai-models-reference-v1.md).
Загрузка настоящего Справочника в production требует разрешения владельца.

## Что делает команда

1. Читает файл со стандартного ввода.
2. Проверяет файл целиком: схему, коды и ссылки, лимиты длины, бюджет байт каждого ответа виджету.
3. Если есть хотя бы одна ошибка, ничего не меняет в базе и печатает отчёт об ошибках.
4. С ключом `--preview` печатает, какую версию запишет загрузка, и ничего не пишет.
5. С ключом `--apply` одной транзакцией записывает файл новой версией Справочника. Если у текущей
   версии то же содержание, новую версию не пишет.

Файл передаётся через стандартный ввод, потому что контейнер команды работает с файловой
системой только для чтения и видит только сеть базы.

## Проверка экранов перед загрузкой

Импорт проверяет байты каждого ответа виджету, но не высоту экрана. Перед загрузкой настоящего
файла в production нарисуйте каждый его экран во встроенном Chromium, из корня репозитория:

```bash
pnpm --filter @inside/telegram ai-models:widget:fit /protected/ai-models-reference.json
```

Команда рисует собранный виджет при ширине 320 и 390 px: каждую страницу каждого фильтра, обе
вкладки каждой карточки и «О данных». В стандартный вывод она печатает по строке JSON на экран и
ширину: запрос экрана (`3lc0`, `3sopus`), байты ответа, высоту `heightPx`, размер шрифта `fontPx`,
обрезаны ли Сводки (`clipped`), есть ли переполнение вбок (`overflow`) и `fits`. Итог по каждой
ширине она пишет в поток ошибок: самый высокий экран, самый мелкий шрифт и число страниц с
обрезанными Сводками. Текстов файла в выводе нет. Код выхода 0 значит, что все экраны помещаются в
560 px при шрифте не меньше 11 px; 1 значит, что какой-то экран не помещается; 2 значит, что файл не
читается или импорт его отклонил. Браузер рисует своими шрифтами, а не шрифтами Telegram, поэтому
небольшой запас по высоте нужен. Вкладка «Подписки» с девятью и больше тарифами с оценками может не
поместиться при ширине 320 px: сократите пояснения тарифов этой модели.

## Запуск в production

Переменная `telegram_compose` задаётся как в разделе
[operations-команд](production.md#operations-команды). Файл Справочника лежит на сервере вне Git.

```bash
"${telegram_compose[@]}" --profile operations run --rm -T ai-models-reference-import --preview < /protected/ai-models-reference.json
"${telegram_compose[@]}" --profile operations run --rm -T ai-models-reference-import --apply < /protected/ai-models-reference.json
```

Сначала выполните `--preview` и прочитайте отчёт. Затем выполните `--apply` с тем же файлом.

## Запуск локально

Из `apps/telegram`, с `DATABASE_URL` своей базы:

```bash
pnpm owner:ai-models-reference-import --preview < docs/integrations/ai-models-reference-v1.example.json
```

## Отчёт

Отчёт печатается в стандартный вывод как JSON. Текстов файла в нём нет.

| `status` | Код выхода | Смысл |
| --- | --- | --- |
| `valid` | 0 | `--preview`: файл корректен, `--apply` запишет версию `revision`; база не менялась |
| `imported` | 0 | `--apply`: версия `revision` стала текущим Справочником |
| `unchanged` | 0 | у текущей версии `revision` то же содержание; база не менялась |
| `rejected` | 2 | файл отклонён, база не менялась |

Код выхода 1 означает, что команда вызвана неверно, файл не является JSON или база недоступна.
База при этом не меняется.

Корректный файл:

```json
{
  "status": "imported",
  "revision": 3,
  "checkedOn": "2026-11-12",
  "services": 8,
  "plans": 24,
  "models": 13,
  "largestAnswer": { "request": "3lc0", "bytes": 796 }
}
```

`services`, `plans` и `models` считают записи файла. `largestAnswer` называет самый длинный ответ
виджету и его размер в байтах; лимит 1 024. Запрос `3lc0` значит первую страницу фильтра
«Дёшево», `3sopus` значит вкладку «Подписки» модели `opus`.

Отклонённый файл:

```json
{
  "status": "rejected",
  "errors": [
    { "model": "glm", "field": "summary", "reason": "Знаков 57, лимит 50." },
    { "plan": "g-pro", "field": "usdPerMonth", "reason": "Не больше двух знаков после точки." }
  ]
}
```

Каждая ошибка называет кодом модель (`model`), тариф (`plan`), сервис (`service`) или группу
«Мой выбор» (`group`), поле и причину. Ошибка бюджета называет ещё запрос виджета (`request`).
Если сам код сломан, вместо него стоит номер записи в файле, например `№3`. Поле мнения автора
начинается с `author.`, например `author.badges.0.text`.

## Откат

Чтобы вернуть прежний Справочник, загрузите прежний файл с `--apply`. Он станет новой версией;
все версии остаются в базе.
