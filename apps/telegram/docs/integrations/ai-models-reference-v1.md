# Файл Справочника «ИИ-моделей», версия 1

Это контракт между исследованием владельца и ботом. Владелец собирает Справочник раздела
«ИИ-модели» в один файл JSON и загружает его в базу бота [командой импорта](../operations/ai-models-reference.md).
Решения о составе файла приняты с владельцем 12.11.2026 для спецификации
[#2034](https://github.com/sachkov-inside/platform/issues/2034).

В этом репозитории нет настоящего Справочника. Пример и тесты используют синтетический файл с
выдуманными моделями и сервисами.

| Файл | Назначение |
| --- | --- |
| [ai-models-reference-v1.schema.json](ai-models-reference-v1.schema.json) | JSON Schema формы файла и лимиты в поле `x-limits` |
| [ai-models-reference-v1.example.json](ai-models-reference-v1.example.json) | синтетический пример корректного файла |

Схему нельзя править руками. Она собирается из схемы, по которой проверяет импорт
(`src/modules/ai-models/ai-models-reference-file.ts`), командой
`pnpm --filter @inside/telegram ai-models:reference:schema`. Проверка
`pnpm --filter @inside/telegram check` падает, если опубликованная схема отстала от кода.

## Состав файла

Файл хранит весь Справочник целиком. Кодировка UTF-8. Неизвестное поле отклоняет файл, чтобы
опечатка в имени поля не прошла незаметно.

| Поле | Смысл |
| --- | --- |
| `format` | всегда `inside.ai-models-reference.v1` |
| `checkedOn` | дата проверки фактов `ГГГГ-ММ-ДД`; человек видит «Проверено ДД.ММ», а на экране «О данных» полную дату |
| `about` | от 1 до 6 строк экрана «О данных»: источники и как читать оценки |
| `services` | сервисы, которые продают Подписки сервисов |
| `plans` | тарифы сервисов |
| `models` | от 1 до 20 моделей |
| `author` | мнение автора; бот хранит его отдельно от фактов |

Коды сервисов, тарифов, моделей и групп постоянные: строчные латинские буквы, цифры и дефис, до
16 знаков, первый знак буква или цифра. Код модели виджет отправляет в запросе карточки. В каждом
списке коды не повторяются.

**Сервис** (`services`): код `code`, название `name` и две пометки про Россию: `fromRussia`
(работает ли из России) и `russianCard` (принимает ли российскую карту). Значения пометок: `yes`
да, `no` нет, `unknown` нет данных.

**Тариф** (`plans`): код `code`, код сервиса `service`, название тарифа без названия сервиса
`name`, цена в долларах в месяц `usdPerMonth` и `priceFrom`. Цена больше нуля, не больше двух
знаков после точки. `priceFrom: true` показывает цену как «от $6»: у тарифа несколько уровней.

**Модель** (`models`):

| Поле | Смысл |
| --- | --- |
| `code` | постоянный код |
| `name` | название модели |
| `family` | Семейство, например Claude |
| `arenaRank` | место в таблице агентов Arena, целое от 1; у каждой модели своё |
| `taskUsd` | цена одной задачи по API в долларах, по Arena |
| `apiUsdPerMillionTokens` | цена миллиона токенов на вход `input` и на выход `output` |
| `tags` | от 1 до 5 разных Меток задач: `code` код, `texts` тексты, `research` поиск и анализ, `agents` агенты, `cheap-bulk` дёшево и много |
| `summary` | Сводка модели |
| `agent` | Лучший агент: название `name`, основание `basis` (`measured` по замерам, `vendor` советует компания) и причина `reason` |
| `alternatives` | хорошие альтернативные агенты одной строкой |
| `subscriptions` | до 12 Подписок сервисов с этой моделью, в порядке показа |
| `notice` | необязательное объявленное изменение цены или конец акции, с датой |

**Подписка модели** (`subscriptions`): код тарифа `plan` и ровно одно из двух:

- `estimate`, Оценка подписки: `basis` и `apiUsdPerMonth`, сколько стоил бы тот же объём работы по
  ценам API в долларах в месяц. `basis: measured` означает независимый замер, и тогда `accounts`
  (число замеренных аккаунтов) обязательно и не меньше 5. `basis: vendor-dollar-limit` означает,
  что компания сама называет лимит в долларах (сейчас это OpenCode Go); `accounts` у него нет;
- `vendorWording`, слова компании о лимите, когда оценки нет.

Ещё у подписки есть необязательные `promo: true` (модель есть в тарифе только по акции) и `note`
(короткое пояснение к строке тарифа). Один тариф встречается в подписках модели один раз.

**Мнение автора** (`author`):

| Поле | Смысл |
| --- | --- |
| `favoriteGroups` | группы фильтра «⭐ Мой выбор» в порядке показа: код `code` и название `title` |
| `services` | Риск бана по кодам сервисов: уровень `banRisk` (`high`, `medium`, `low`), пояснение `text` и коды моделей `models`, которые получают значок «Риск бана» |
| `models` | мнение по кодам моделей: значки `badges`, совет `advice` и «Лучше взять» `betterPick` |

Значок (`badges`) состоит из вида `badge`, пояснения `text` и, только у вида `favorite`, кодов
групп `groups`. Виды: `favorite` «⭐ Мой выбор», `confident` «Уверенная», `mid-tasks` «Требует
контроля», `pricey` «Дорого», `wasteful` «Невыгодно». У модели каждый вид встречается один раз.
«Лучше взять» состоит из одной или двух других моделей `models` и причины `reason`.

## Правила сверх схемы

Импорт проверяет файл целиком и при любой ошибке ничего не меняет. Числа лимитов лежат в
`x-limits` схемы.

1. Коды в каждом списке не повторяются, места в Arena у моделей разные.
2. Каждая ссылка ведёт на запись файла: тариф на сервис, подписка на тариф, риск бана на сервис и
   модели, мнение автора на модель, группа значка на `favoriteGroups`, «Лучше взять» на модели.
   «Лучше взять» не указывает на саму модель и не повторяет модель.
3. Значку `favorite` нужна хотя бы одна группа, и только у него есть группы. В каждой группе есть
   хотя бы одна модель.
4. Подписка имеет ровно одно из `estimate` и `vendorWording`. Оценка по замеру требует не меньше
   `measuredAccountsMin` аккаунтов.
5. Тексты не пустые, без знака `|`, и не длиннее своего лимита в знаках. Знак `|` разделяет поля
   строки списка в ответе виджету.
6. Каждый ответ виджету, который можно получить из файла, укладывается в `widgetDataBytes` байт:
   каждая страница каждого фильтра, обе вкладки карточки каждой модели и экран «О данных».
   Каждый запрос виджета укладывается в `widgetRequestBytes` байт.

Импорт проверяет правило 6, только когда остальные выполнены. Ошибка бюджета называет запрос
виджета, например `3lc0` (первая страница «Дёшево») или `3sopus` (вкладка «Подписки» модели
`opus`), и число байт. Самые длинные тексты стоят в списке и на вкладке «Главное»: если ответ не
помещается, сократите названия и Сводки моделей этой страницы или тексты карточки.

Длина считается в знаках после приведения текста к составной форме Юникода (NFC). Пробелы по
краям текста импорт убирает. Байты считаются в UTF-8 вместе с JSON-обёрткой ответа: кириллица
занимает 2 байта на букву, знаки вроде `€`, `≈` и `→` занимают 3 байта. Поэтому текст может пройти
по знакам и не пройти по байтам.

## Как бот показывает данные

Правила считает бот, виджет только раскладывает готовые значения.

- **Мощность**: места 1–10 в Arena дают 5 точек, 11–20 дают 4, 21–30 дают 3, 31–40 дают 2, ниже 1.
  У мест 1 и 2 последняя точка цветная.
- **Уровень цены** по цене задачи: от $5 это 5, от $2 это 4, от $1 это 3, от $0,30 это 2, дешевле 1.
- **«Мощные»**: все модели по месту в Arena, по 7 на странице.
- **«⭐ Мой выбор»**: группы в порядке `favoriteGroups`, в группе модели по месту в Arena. Модель
  может стоять в нескольких группах. Значок «Мой выбор» в этом фильтре не повторяется. На странице
  до 7 моделей; группа, которая продолжается на следующей странице, повторяет там название.
- **«Цена/качество»**: модели, для которых нет другой модели одновременно выше в Arena и дешевле
  за задачу, по цене задачи.
- **«Дёшево»**: все модели по цене задачи, рядом самый дешёвый тариф без акции или «только API».
- **Значки строки**: значки автора и «Риск бана», если модель названа у сервиса в
  `author.services`, в порядке «Мой выбор», «Уверенная», «Требует контроля», «Дорого»,
  «Невыгодно», «Риск бана».
- **Деньги**: цены тарифов и задач целыми долларами или с двумя знаками после запятой ($19,99).
  Оценка подписки до $100 целыми, до $1 000 до десятков, выше до сотен ($670, $7 000). Тысячи
  отделяются неразрывным пробелом.
- **Оценка подписки**: по замеру «≈ $670», по лимиту в долларах «$100» без «≈». Кратность к цене
  тарифа от 10 целая, ниже с одним знаком после запятой, со словом «раз» или «раза»
  («в 33 раза», «в 21 раз», «в 1,5 раза»). Если оценка не больше цены, кратности нет.
- **Тарифы**: на вкладке «Подписки» тарифы собраны по сервисам в порядке подписок модели. Соседние
  тарифы одного сервиса с одинаковыми словами компании, пояснением и пометкой акции
  сворачиваются в одну строку «Plus–Ultra · от $19».

Форма каждого ответа описана в `src/modules/ai-models/widget/ai-models-widget-wire.ts`.

## Что делает повторная загрузка

- Файл с новым содержанием становится текущим Справочником. Люди сразу видят новые данные и
  новую дату «Проверено».
- Прежние версии остаются в базе как история. Чтобы вернуть прежний Справочник, загрузите прежний
  файл: он станет новой версией.
- Файл с тем же содержанием, что у текущей версии, новую версию не пишет. Пробелы по краям
  текстов, отступы и порядок ключей содержание не меняют.
- Факты и раздел `author` хранятся в разных полях версии, чтобы будущая Ежедневная проверка
  меняла только факты.
