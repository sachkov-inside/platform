# Проверка сценариев ученика, #1496

Снимки показывают реальные компоненты продолжения на Platform с тестовыми данными Storybook.
Координатор снял их 15 октября 2026 года с локального сервера на порту 6156.
На мобильном экране шириной 390 px он проверил отсутствие горизонтальной прокрутки.

В тесте вступления бот обработал 100 подготовленных запросов с настоящей PostgreSQL.
Тест использовал настоящие inbox, активацию, admission и outbox, но управлял ответами Platform и Telegram.
Он измерял время от приёма действия до пригодного результата отправки или редактирования сообщения.
Компиляция, миграции, привязка и первый полный запрос завершились до измерения.
Для каждого запроса тест проверял новый ответ с отдельным номером карточки.
Ответ первого запроса для прогрева не мог подтвердить последующие запросы.
Последний запуск показал p95 64,99 мс, 0 ошибок и 0 исключённых сбоев при Node.js 26.10.0.
p95 означает, что 95 из 100 запросов завершились не медленнее указанного времени.

Из корня репозитория проверку повторяет команда:

```bash
DATABASE_URL=<owned-test-database> pnpm --filter @inside/telegram exec vitest run \
  --config vitest.integration.config.ts \
  test/integration/subscription-activation.integration.test.ts \
  -t 'measures prepared normal admission'
```

Эти снимки и измерение не подтверждают задержки производственных сетей или вход через мобильный Telegram.
После выпуска остаются реальная проверка мобильного браузера, открытия группы и пересылки объявления с кнопкой.
Первая реальная привязка новой личности отдельно ожидает проверки в [#1493](https://github.com/sachkov-inside/platform/issues/1493).
