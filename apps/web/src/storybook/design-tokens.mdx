# Design tokens

Tokens name product roles instead of individual screens. Their values live in
`apps/web/app/globals.css`, which both the application and Storybook import, and reach components
through Tailwind theme aliases. The product has one light theme in two palettes:

- `:root` is the authoring palette: the warm olive canvas of `/authoring`.
- `[data-public-shell]` overrides it on every public page: white canvas, charcoal text and a
  terracotta accent. The public shell and its portalled menus carry this attribute.

## Color roles

export const roles = [
  ["Background", "--background", "bg-background text-foreground"],
  ["Card", "--card", "bg-card text-card-foreground"],
  ["Primary", "--primary", "bg-primary text-primary-foreground"],
  ["Secondary", "--secondary", "bg-secondary text-secondary-foreground"],
  ["Accent", "--accent", "bg-accent text-accent-foreground"],
  ["Destructive", "--destructive", "bg-destructive text-white"],
];

export const Swatches = () => (
  <div className="not-prose grid gap-3 sm:grid-cols-2 lg:grid-cols-3">
    {roles.map(([label, token, classes]) => (
      <div
        className={`rounded-xl border border-border p-4 ${classes}`}
        key={token}
      >
        <div className="font-semibold">{label}</div>
        <code className="mt-2 block font-mono text-xs opacity-75">{token}</code>
      </div>
    ))}
  </div>
);

### Шкала шрифтов публичных страниц

Стандарт владельца от 09.10.2026: на телефоне текст на ступень мельче, чем на широком экране, —
как в программе продукта. Новые страницы и карточки берут размеры из этой таблицы.

| Роль                                | Телефон, до 48rem   | Широкий экран             |
| ----------------------------------- | ------------------- | ------------------------- |
| Название страницы или продукта      | 20–32 px            | 24–36 px                  |
| Заголовок блока                     | 20 px               | 22–24 px                  |
| Заголовок карточки, строки, вопроса | 15 px               | 16–17 px                  |
| Основной текст                      | 14 px               | 15–16 px                  |
| Текст карточки, описание            | 13,5–14 px          | 15 px                     |
| Подписи, метки, счётчики            | 12–13 px            | 12–14 px                  |
| Тип урока капителью                 | 9 px                | 10 px                     |
| Кнопка                              | 15 px, высота 44 px | 15–16 px, высота 44–48 px |

## Shape and elevation

Controls use the shared radius scale; cards use restrained elevation only where the surface is
interactive. Focus is always communicated by the semantic `ring` token and remains visible in
forced-colors mode. Motion is brief, purposeful, and disabled under `prefers-reduced-motion`.
