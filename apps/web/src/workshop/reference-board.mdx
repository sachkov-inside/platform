# Navigation reference board

The first bounded decision is application navigation topology. References are inputs, not screen specifications.

## Expandable sidebar · Manu Arora / Aceternity UI

- Source: [21st.dev](https://21st.dev/@manuarora700/components/sidebar)
- Take: compact icon rail, optional expansion, profile utility at the bottom, a clearly bounded work surface.
- Adapt: optional pin mode, keyboard-visible labels and focus expansion instead of hover-only access; persistent mobile bottom navigation instead of a burger or Sheet.
- Do not take: dashboard placeholder cards, dark-only product identity, remote avatar, generic Dashboard/Profile/Settings taxonomy.

## Sachkov Inside visual input

- Take: calm light canvas, charcoal workbench regions, restrained orange current-state signal, Manrope body and JetBrains Mono for genuine technical metadata.
- Accepted globally: rounded auto/pinnable desktop sidebar and persistent mobile bottom navigation.
- Keep open: exact production token values and contextual navigation inside Library, Material and authoring surfaces.
