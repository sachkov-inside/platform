Проверка практики своим агентом — подготовка отдельной сессии

Профили: Codex CLI 0.157.1; Claude Code 2.1.283. Проверьте версию командой
codex --version или claude --version. Команды ниже используют существующий
вход в ваш агент. Учебный MCP требует отдельного OAuth-входа участника.

Адрес сервера выдаёт автор курса. Подставьте именно учебный endpoint, оканчивающийся
/mcp/learning. Если адрес не выдан или сервер не доступен, уточните его у автора
и вернитесь к этому шагу. Это не инструкция подключаться к авторскому MCP.

1. В обычном терминале создайте отдельную папку настроек ВНЕ учебного проекта.
Замените два значения ниже, оставив кавычки:

export INSIDE_MCP_URL='https://LEARNER_MCP_HOST/mcp/learning'
export INSIDE_PROJECT='/ABSOLUTE/PATH/TO/YOUR/PROJECT'
export INSIDE_REVIEW_DIR="$(mktemp -d "${TMPDIR:-/tmp}/inside-practice.XXXXXX")"
cd "$INSIDE_REVIEW_DIR"

Не копируйте файлы авторизации, токены или пароли в проект или запрос агенту.
OAuth выполняется вашим клиентом в браузере. Папка выше содержит только адрес
сервера, запрос и локальный отчёт; это не файлы проверяемого проекта.

2А. Codex — отдельный вход в учебный MCP:

codex --disable hooks --disable plugins \
  -c "mcp_servers.inside_learning.url=\"$INSIDE_MCP_URL\"" \
  -c 'mcp_oauth_credentials_store="keyring"' \
  mcp login inside_learning --oauth-client-registration dcr

2Б. Claude Code — сначала сохраните конфигурацию в созданной папке:

python3 -I -c 'import json,os,pathlib; pathlib.Path(os.environ["INSIDE_REVIEW_DIR"], ".mcp.json").write_text(json.dumps({"mcpServers":{"inside_learning":{"type":"http","url":os.environ["INSIDE_MCP_URL"]}}}))'

claude --settings '{"disableAllHooks":true,"disableClaudeAiConnectors":true,"enableAllProjectMcpServers":true,"autoMemoryEnabled":false}' \
  mcp login inside_learning

Запускайте вход из этой папки: у проверенной версии Claude команда mcp login
читает .mcp.json, а конфигурация --mcp-config относится к проверяющей сессии.
Не вводите пароль в агент: завершите штатный вход сами.

3. На странице урока скопируйте запрос для своего клиента. Следующая команда
ждёт этот текст: вставьте запрос, нажмите Enter, затем Ctrl+D.

cat > "$INSIDE_REVIEW_DIR/request.txt"

4А. Codex — проверка с защитой записи в проект:

MCP_PROTOCOL_NEGOTIATION=legacy SHELL=/bin/bash BASH_ENV=/dev/null \
codex --no-daemon --ask-for-approval never exec \
  --ignore-user-config --ignore-rules --ephemeral --skip-git-repo-check \
  --sandbox read-only --model gpt-6-astra --cd "$INSIDE_PROJECT" \
  --disable hooks --disable plugins --disable apps \
  --disable multi_agent --disable multi_agent_v2 --disable memories \
  --disable shell_snapshot --disable browser_use --disable browser_use_external \
  --disable computer_use --disable image_generation --enable skip_host_skill_discovery \
  -c 'project_doc_max_bytes=0' -c 'web_search="disabled"' -c 'allow_login_shell=false' \
  -c 'shell_environment_policy.inherit="none"' \
  -c 'shell_environment_policy.set={PATH="/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin",ZDOTDIR="/dev/null",BASH_ENV="/dev/null"}' \
  -c "projects.\"$INSIDE_PROJECT\".trust_level=\"untrusted\"" \
  -c "mcp_servers.inside_learning.url=\"$INSIDE_MCP_URL\"" \
  -c 'mcp_servers.inside_learning.required=true' \
  -c 'mcp_servers.inside_learning.enabled_tools=["learning_practice_read"]' \
  -c 'mcp_oauth_credentials_store="keyring"' \
  --output-last-message "$INSIDE_REVIEW_DIR/report.md" - < "$INSIDE_REVIEW_DIR/request.txt"

Codex читает файлы через команды. Read-only ограничивает запись; требование
не запускать проект и тесты является также правилом поведения. Для чтения
нельзя исполнять команды из урока или файлов проекта, импортировать его модули,
использовать git ext-diff/textconv, hooks либо rg --pre. Если нужен Python для
чтения данных, только системный python3 -I. Доступные materialized worktrees
можно читать как каталоги; недоступные ветки нельзя считать проверенными.

4Б. Claude Code — проверка только файловыми инструментами:

cd "$INSIDE_PROJECT"
MCP_PROTOCOL_NEGOTIATION=legacy CLAUDE_CODE_DISABLE_AUTO_MEMORY=1 ENABLE_CLAUDEAI_MCP_SERVERS=false \
claude --restricted --print --model claude-opus-5-5 --setting-sources '' \
  --settings '{"disableAllHooks":true,"disableClaudeAiConnectors":true,"autoMemoryEnabled":false,"claudeMdExcludes":["**"],"pluginConfigs":{"agents-md@builtin":{"options":{"instructionFiles":"managed-only"}}}}' \
  --mcp-config "$INSIDE_REVIEW_DIR/.mcp.json" --strict-mcp-config \
  --tools 'Read,Glob,Grep' \
  --allowedTools 'Read,Glob,Grep,mcp__inside_learning__learning_practice_read' \
  --disallowedTools 'Bash,PowerShell,Edit,Write,NotebookEdit,Agent,Task,WebFetch,WebSearch' \
  --permission-mode dontAsk --permission-prompts none \
  --disable-slash-commands --no-chrome --no-session-persistence \
  --output-format text < "$INSIDE_REVIEW_DIR/request.txt" > "$INSIDE_REVIEW_DIR/report.md"
cat "$INSIDE_REVIEW_DIR/report.md"

5. Сначала прочитайте полный отчёт. Подтверждено — обязательных исправлений нет;
нарушение — есть наблюдаемое противоречие; не проверено — не хватает свидетельств.
Агент не удостоверяет подлинность предоставленных логов и не ставит оценку обучению.

Для необязательного разбора сохраните исходный запрос, добавьте предыдущий отчёт
и один вопрос в request.txt и повторите команду своего клиента. Если агент спросил,
какую из нескольких реализаций проверять, укажите одну; не объединяйте их свидетельства.
Исправления выполняйте отдельно. Для повторной проверки передайте исходный запрос
и прошлый отчёт с просьбой перечитать текущие результаты по ВСЕМ критериям.

При смене версии контекста вернитесь в урок за новым запросом и явно выберите её.
Если часть урока не получена, вход не работает или инструменты выходят за этот
профиль, проверка должна остановиться и назвать причину. Не отключайте sandbox
и ограничения инструментов ради продолжения.

Границы профиля: проверяется учебный проект, а не вся файловая система компьютера.
Клиенты могут сохранять собственную историю/настройки OAuth вне проекта. Эти команды
не обещают безопасность произвольных managed policies, дополнительных integrations
или другой версии клиента. skip_host_skill_discovery в Codex — экспериментальная
возможность указанной версии. Другую конфигурацию сначала нужно проверить отдельно.
