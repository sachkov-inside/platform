commit `1af7b612`, `guest-home-assets/kirill-mini-app.png`. It retains the transparent background.

without changing the pose or composition. The 57 KiB pre-encoded file covers the largest
288 CSS px rendering at DPR 3 and is served without a second image transformation.
The calm portrait and exploratory alternatives remain in the prototype branch.
